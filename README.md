# 棋院 · 长期记忆系统（dsh-gokifu-longmemory）

> 给 DSH 的长期记忆插件：**让模型下次别再踩同一个坑。**
> 每局会话结束后，把「踩过的坑 + 当时怎么修好的」记下来；下次遇到类似任务，把这条经验递给它——**只给事实，不给指令**，模型自己会避开。

## 它能做什么

- **失败教训**：记住你在哪踩过坑、报了什么错。
- **恢复事实**：记住那个坑**后来是怎么修好的**（同一命令后来成功了、同一文件后来写对了）。
- **不相关时沉默**：没用的记忆不塞给你（而且不会把该给的错拦）。
- **每条都有出处**：哪一局、哪一行、哪一天，**没有一句是编的**。

它**不做**：压缩、工具、系统提示词、用户画像。**只做「能改变下次行动」的记忆。**

## 怎么装 / 怎么开

**普通用户：打开 `dsh-gokifu-longmemory` 这一个开关就够了。**

1. 把本插件放进 DSH 的插件目录，并在 profile 里启用 `dsh-gokifu-longmemory`。
2. 重启 DSH，记忆开始工作。

> **`kifu-loader` 不用管**——那是**开发专用**的软链加载器（改源码不用重装）。正常用户**不需要**它。
> **`dsh-gokifu-longmemory` 和 `kifu-loader` 只开一个**（两个都开会重复注入）。

## 和其他记忆插件的关系

如果你同时装着 **Hindsight**（`@vectorize-io/hindsight-coding-agents`）：那是**另一个独立的记忆系统**，和本插件互不影响。**想只用本插件，把 Hindsight 关掉即可。**

## 一句话理念

记忆的目的不是「记住你」，是「**下次做得更好**」。
所以这里存的不是你的画像，是**「这个坑怎么避、上次怎么修好的」**——能直接改变模型下一次行动的东西。
