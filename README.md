# 棋院 · 长期记忆系统（M1 完成 · v0.2.0）

> DSH 的长期记忆插件：每局棋谱入馆，**所有相关边与节点连成一张网**，并提炼**定式**（多源公认、每招指回源头棋谱）；新会话遇到相关主题时**顺藤摸瓜**跳过去，**棋书馆不是分类柜子**；先取已付过代价的失败（不重复踩坑），成功经验只作参考且必须带适用条件；**面向模型，不面向人**；**硬约束：至少比 Hindsight 强**。
> 它只做记忆——不压缩、不做工具、不改系统提示词、不写 AGENTS 规则。边界见 `docs/记忆的职责边界.md`。
