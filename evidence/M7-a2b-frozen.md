# M7 · A2b 冻结评估集（2026-11-02）

## 问题
A2b 的分母一直在变：18 → 19 是因为类级章节自愈让一条签名变得可评测。
样本仅 19 条 ⇒ **1 条 = 5.3pp**，分母漂移会把 63.2% 与 66.7% 的差别伪装成"回归/提升"。

## 做法
- `scripts/a2b-set.mjs --freeze`：把「切点（2026-11-02T00:00Z）之后、且当年有先例」的失败签名固化成
  `evidence/a2b-set.json`（含 `sig / scopeKey / episode / prior[] / sameScope`）。
- `m5-report` 与 `metrics-guard` 自动读取该快照；没有快照才回退到动态计算。
- 快照是**只读输入**：不写 store、不改 claim。

## 当前快照
```
A2b 冻结集：19 条 · 冻结于 2026-11-02T11:21:02Z · 同域可达 9
metrics-guard PASS · A2b严格=0.6316（n=19） 覆盖=1 p50=2.04ms
```

## 纪律
1. 快照一旦冻结，**不得为了让数字好看而重冻**；重冻必须在 PR 里写明理由（语料/口径变更）。
2. 以后对比"提升"用同一份快照；若要评估新语料，另建 `a2b-set-2.json` 并两套都报。
