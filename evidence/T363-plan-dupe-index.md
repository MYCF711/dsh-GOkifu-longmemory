## 二、为什么不重编号

重编号会牵动 `CHANGELOG.md`、`evidence/`、PR 正文里的几十处交叉引用，**有代价**（且不可逆地改写历史）。
所以这一刀只**把重号摊开**：

- 新增 `scripts/plan-dupe-index.mjs`（只读生成，`--write` 写回固定区块）；
- `计划表.md` 末尾追加「重号索引」区块，由 `<!-- dupe-index:begin/end -->` 包住，可随时重算；
- 区块开头写明**判读规则**：同一编号出现两次时，行号大的那条通常是后来的改判或续记。

## 三、门禁

```
node scripts/plan-dupe-index.mjs --write   → 42 个重号
node scripts/check.mjs                     → PASS
```
