# T306 · 剂量-反应：记忆强度 → 同错复发率（只读）

> `[本] 2026-11-06 13:25 +08:00` · **只读**：不写库、不改任何 claim；未跑全量测试、未重启 DSH
> 脚本：`scripts/dose-response.mjs` · 单测：`test/dose-response.test.mjs`（3 条）
> 语料：T279 那 20 局（非本仓、按 `signals.failures` 降序），**未换**；分层档位**跑前定死**：0 / 1 / 2-3 / 4+

## 0 · 一句话结论

**没有剂量-反应关系。** 复发率随记忆强度**先升后回**：0 次 **11.62%** → 1 次 **28.57%** → 2-3 次 **35.00%** → 4+ 次 **11.76%**。
**记忆强度最高的那一层（4+）回到基线，而不是更低** ⇒ **不能证明"记忆有用"**。
按你的话：**我们该承认"还没证明它有用"**。

**每层样本量必须看**：1 次层只有 **21** 条、2-3 次层 **20** 条、4+ 层 **17** 条 —— **三层的 Wilson 区间全部跨过基线**（例如 4+ 的 [3.29%, 34.34%] 完全包含 11.62%）。**这些层不能当效应量。**

## 2 · 判据判定

| 判据 | 要求 | 实测 | 结论 |
|---|---|---|---|
| 单调下降 | 每层 ≤ 上一层 | **否**（两处上升） | **不成立** |
| 最高强度层低于基线 | 4+ < 0 | **11.76% vs 11.62%（+0.14pp，区间重叠）** | **不成立** |
| 负向对照（0 次层） | 提供基线 | 11.62%（n=5413，最稳的一层） | 已提供 |
| 效应量可信 | 每层 n ≥ 30 | 三层全部 < 22 | **不可信** |

**⇒ 没有剂量-反应关系；也没有"记忆越强复发越少"的证据。**

## 3 · 为什么"1 次/2-3 次"反而更高（诚实解释）

1. **选择偏差仍在**：claim 只从"被抽取过的失败"里来，而"同一签名出现两次"更容易被抽成 claim ⇒ 中间两层天然富集"会复发"的签名。4+ 层反而回到基线，可能说明"反复被记住的签名是那些**跨局通用**的错误（如 `exit code 1`），它们在单局内不一定复发"。
2. **样本量断崖**：5471 个签名里只有 **58** 个（21+20+17）落在"有记忆"的三层，其余 5413 个是 0 次层 —— 曲线几乎全是基线，**这个分布本身说明"记忆覆盖极稀疏"**（与 T291 的 77.87% 主局覆盖一致：覆盖的是局，不是签名）。
3. **没有干预**：本刀仍是回放观测，不是 ablation。

## 4 · 结论

- **没有剂量-反应关系。**
- **不能证明"记忆有用"。** 按 T305 的结论，这是第二条独立的负面证据（不同设计、同一结论）。
- **下一步若还要证**：需要**真 ablation**（控制注入开关）或**跨局配对**（同一签名在"父局有 claim"与"父局无 claim"两组局之间的复发率），而不是继续在观测数据上切分层 —— 已经切了两次（二分组 + 四分层），都没有信号。
