# N4 否决：卷级降级没有消费者（2026-11-03）

## 假设（来自 RAPTOR，见 `docs/调研/20`）
当卡片里条目级内容为空（全部被闸拦 / 预算不够）时，改为输出**卷级 headline** 作为"指针"，
让模型至少知道"这一类有 N 局、去 `cli volumes` 看"。

## 前提是"空卡"常见——实测不是
用 `replay-live` 跑 **39 局真实会话**（真实日志 + 真实插件 + 真实 store）：

| 指标 | 实测 |
|---|---|
| 会话数 | 39 |
| **零注入（空卡）** | **0** |
| 注入 | 39（每局至少一刀命中） |
| 注入路径延迟 | p50 15.1ms · p95 20.1ms |
| 溯源引用 | 158 条 · 跨作用域 **0** |
| warn | 2 条，均为 `gate4/unsuperseded-duplicate`（**闸按设计拒绝**，不是错误） |

## 结论
**N4 否决**：在真实语料上，"空卡"出现次数为 **0/39**，降级路径永远走不到 ⇒ 没有消费者，
按"指标先有消费者"的纪律不做。若将来零注入比例上升（例如闸更严或预算更小），N4 可以重开，
判据就是"零注入率 > 5%"。

## 附带观察（不计失分，但要记）
- 2/39 局首刀被 `gate4/unsuperseded-duplicate` 拦住：说明**重复 claim 未标 supersedes** 是真实存在的形态；
  它们第二轮仍注入了（oncePerSession 未被占），所以会话层面没有"沉默"。
- 这条观察支持审计早前把 `supersedes` 列为"保留字段/无生产者"的判断：需要有人先决定"何时算 supersede"。
