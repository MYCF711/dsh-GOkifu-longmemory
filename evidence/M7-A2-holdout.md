# M7 · A2 口径修正：加时间切分 holdout（2026-11-02）

## 发现的问题
全量 LOO 的 memory 会随时间增长（D1 每次归档都会把新局并入），所以 **A2 的 repeat 率会自然上升**。
过去几条 CHANGELOG 把 21.97% → 24.32% 之类的变化归因于当期改动，**跨时点不可比**（违反 AGENTS §2.4「指标本身要被验证」）。

## 修正
`scripts/eval.mjs` 的 `runEval` 新增 `splitAt`：
- memory = `startedAt ≤ splitAt` 的局；test = 更晚的局；
- 只统计像错误的签名（与主口径一致）；
- `m5-report` 固定 `splitAt = 2026-11-02T00:00:00Z`，A2 同时输出两个数。

## 当前值（同一个 store，同一时点）
| 口径 | 值 | 样本 |
|---|---|---|
| 全量 LOO（会随语料增长） | 24.67% | repeat 37 / novel 113 |
| **时间切分 holdout**（可跨时点比较） | **35.56%** | 16 / 45（test 9 局） |

## 结论与纪律
1. 以后**声称 A2 提升必须给 holdout 值**；全量 LOO 只作趋势参考。
2. 已发布版本里的历史 A2 增量（23.40/23.61/23.97/24.32 等）**不代表同期代码收益**，不追认。
3. holdout 的 test 只有 9 局，置信区间宽（1σ ≈ ±7pp），后续语料增多再收紧。
