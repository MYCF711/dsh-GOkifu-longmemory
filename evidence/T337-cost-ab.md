# T337 · cost 同分次序的 A/B 对照（评测保真度 + 主判据零影响）

> `[本] 2026-11-06` · **只读**（不写库、不改 claim、零模型调用）。
> 同题（冻结考卷 114 题）、同库、同代码，唯一变量 = 传不传 `costIndex`。

## 0 · 一句话

**把 `costIndex` 接进评测（镜像线上）后，主判据严格命中 58/114 = 50.88% 一字不变，逐题翻转 0。**
这**实证**了 cost 同分次序对召回相关度**零影响** —— 是真的不损害，不是 0.2.75 那种「没接线所以假称不掉」。

## 1 · 为什么必须做这把尺

- **T335（0.2.75）的隐患**：当时测「cost 与文本相关正交」得出 `P(cost>0)=0/392`，
  根因是 `buildMemoryCard` 调用**没传 `costIndex`** ⇒ cost 恒 null ⇒ 「主判据不再掉」是**没接线**造成的假象。
- **T336（0.3.1）** 把 sidecar 填出 **110 条非零 cost**（重锚定）后，数据前提成立。
  但**线上 `plugin.mjs` 传 `costIndex`（T332 已接线），评测 `a2b-holdout.mjs` 却没传** ——
  主判据测的是「不带 cost 排序」的旧行为，**与线上脱节**（评测保真度问题）。
- 本刀：给评测接上 `costIndex`（镜像线上），并**真测**它对主判据的影响。

## 2 · 改动

| 文件 | 改动 |
|---|---|
| `scripts/a2b-holdout.mjs` | `runHoldout` / `replayFrozen` 增加 `costIndex = null` 参数（默认 null 向后兼容），透传到 `buildMemoryCard`；`main` 从 sidecar `<store>/corpus/antipattern-cost.json` 读 `costIndex` 并传入（镜像 `src/plugin.mjs` 的 `decidePreStep`，缺失 ⇒ null ⇒ 不过滤）。 |
| `scripts/cost-ab.mjs` | **新增**：同一冻结考卷重放两遍（A 不传 / B 传），输出主判据 A/B + 逐题翻转。 |

## 3 · 实测

```
costIndex: 1105 条（非零 110）· 考卷 114 题（冻结重放）

主判据（严格命中）：
  A 不传 costIndex : 58/114 = 50.88%
  B 传 costIndex   : 58/114 = 50.88%  （镜像线上）
  Δ = 0.00pp · hashMismatch A=0 B=0

逐题翻转：变好 0 · 变坏 0 · 净 0
```

复算：`node scripts/cost-ab.mjs`（`--json` 出机读）。两次跑数字一致。

## 4 · 结论与边界

- **主判据零影响**：cost 同分次序是**次级排序**（仅当主键全同才调整先后），在这 114 题的卡片里
  未触发任何 strict 判定翻转。⇒ 接上它**不损害**召回相关度，可安全镜像线上。
- **诚实边界**：`Δ=0` 同时说明 cost 次级排序在当前考卷里**也没带来可测的 strict 提升**。
  「付过代价排前」的价值不在 A2b（召回相关度）这把尺上体现 —— 它服务于「先取已付过代价的失败」
  这一**排序偏好**，其收益需由第一验收面（不重复踩坑）的干预实验来证，而非本尺。
- **基线口径**：此处 50.88% 是 `replayFrozen` 重放冻结考卷的严格命中；
  与 `m5-report` 的 A2（20.34%，不同口径）不可直接比。本实验的价值在 **A/B 同尺对照**，不在绝对值。
