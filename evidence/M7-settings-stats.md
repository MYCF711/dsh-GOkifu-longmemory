# M7 · 设置页显示库状态（2026-11-02）

## 动机
设置卡片此前只有地址输入框：用户看不到「库有多大、什么时候更新」，也不知道自动建库是否成功。

## 改动
- `GET /kifu-longmemory/config` 增加 `stats: { exists, episodes, claims, updatedAt }`
  （只读目录计数 + manifest.updatedAt；任何异常回落 null/不存在，不编造数字）。
- 浏览器半侧显示一行：`当前库：116 局 · N 条教训 · 更新于 2026-11-02 16:30`；
  库不存在时显示「下一次会话会自动建库（约十几秒，期间沉默）」。
- 不新增写路径、不改注入内容。

## 验证
- 新增 2 条接口测试（库不存在 ⇒ exists=false 且不编数字；有库 ⇒ 局数/教训数/updatedAt 正确）。
