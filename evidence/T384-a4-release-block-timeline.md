## 三、真实成本在哪

profile（真库 13212 主题 / 29293 links / 5396 claims）：

```
readFileUtf8 278ms · readKindBundle 246ms · overlaps 227ms · walkFromSignals 215ms · createWalkCache 186ms · GC 149ms
```

`readFileUtf8`/`readKindBundle`/`createWalkCache` 是**一次性**（每次进程/build 一次），
真正的 **per-run** 成本是 `walkFromSignals` + `overlaps` + card/gates —— 在 13k 主题规模下稳定在 60–80ms。

## 四、这意味着什么（给主人的一句话）

**语料每天在长，绝对阈值必然越来越难达；它抓到的其实是"数据变多"，不是"代码变慢"。**
`scripts/a4-baseline.mjs`（已合入）能把"同语料下相对基线退化"量出来 —— 那才是真该防的。

**要不要把 A4 从绝对 50ms 切到相对判据，是 D7，等主人裁定。**
在那之前：**不调门槛、不改判据、不把 tag 硬发**。
