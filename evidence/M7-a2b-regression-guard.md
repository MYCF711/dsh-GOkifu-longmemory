# A2b 回归线：从「绝对下限」加一条「不许慢慢烂掉」（2026-11-03）

## 问题
`metrics-guard` 原来只有绝对下限 `a2bStrictMin = 0.55`。
当前严格召回 84.2%，如果某次改动把它拉到 **56%**，护栏仍然 **PASS**——
这正是"每次掉一点、没人发现"的典型形态（审计反复强调的"指标要能被验证"）。

## 修法（只加护栏，不改行为）
- 新增 `a2bStrictRef = 0.8421052631578947`（冻结考卷当前基线）与 `a2bStrictDropMax = 0.10`；
- 判据：`strict < ref − 10pp` ⇒ **FAIL**，失败理由写明「掉了 X.Xpp」；
- 绝对下限 0.55 保留（双闸：一个防崩、一个防滑）。

## 实测
```
metrics-guard PASS · A2b严格=0.8421（n=19）
单测：0.842 持平 PASS ｜ 0.76（−8pp）PASS ｜ 0.70（−14pp）FAIL 且理由含「掉了」
402 条测试（398 pass / 0 fail / 4 skip）
```

## 边界
- 基线是**冻结考卷**上的值，随语料/冻结集变化需手动更新（改基线本身会进 CHANGELOG，可审计）；
- 阈值 10pp 的依据：19 条样本下 1 条 = 5.3pp，10pp ≈ 2 条，低于此可视作波动。
