# M7 · 首条消息里的类级错误信号（2026-11-02）

## 动机
用户常把报错原文贴进首条消息（"又报这个错…"）。此前只按主题/实体匹配，**类级错误主题没有消费方**，
D2 合并出来的 `class:fs-read-before-write` 只能靠 claim 文本包含才被用到。

## 改动
- `decidePreStep` 建信号后调用 `errorClassKeyOf(text)`；命中就追加实体 `{kind:'error', key:'class:<name>'}`。
- `matchTopics` 对 entity 走 exact 匹配（score=1）⇒ 直接命中 class 主题 ⇒ 关联到所有发生过该类错误的棋谱。

## 实测
| 轴 | 改前 | 改后 |
|---|---|---|
| A2 收益（LOO） | 23.40% | **23.61%**（+0.21pp，n=144） |
| A1 负迁移 | 0.00% | 0.00% |
| A4 p50 | 1.78ms | 1.78ms |

## 限制
- 只在首条消息里出现**已知五类报错原文**时生效；泛化到任意错误码需要先扩充类表。
