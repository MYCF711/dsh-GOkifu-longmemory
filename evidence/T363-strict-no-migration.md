# T363 · 严格口径**不需要**迁移：两种定义下结果完全一致（否定性结论）

> 日期：2026-11-07 · 只读分析（未改任何判据 / 未改门槛）
> 结论：**不要**把严格命中从"同局"放宽到"内容相关" —— 实测两种口径**结果相同**，放宽只会引入误判。

## 起因

T362 把**覆盖率**从"同局"迁到"内容相关（不限局）"（66.9% → 79.7%），因为旧口径把跨局的相关记忆判为不相关。

当时我标注：**严格命中要不要也迁，是"放宽"，需要单独裁定**。
本轮就是那次裁定。

## 实测（n=118，考卷原生行级字段）

判据：
- 旧严格：`hitStrict`（考卷原值，同局且满足严格条件）
- 新严格：卡上存在 `strict || strictTokens || strictByBigramOnly` 为真的行（**不限来源局**）

```
旧严格（同局）            55 = 46.6%
新严格（内容相关，不限局）  55 = 46.6%

两口径都命中 55 · 仅旧 0 · 仅新 0 · 都未命中 63
```

**两种严格口径完全相同（同一批 55 条）。**

## 结论

**严格条件足够强，只有同局的 claim 才能满足** —— 不存在"跨局的严格命中"。

⇒ **严格口径不需要迁移**，它已经是准的。

## 为什么这条"否定性结论"值得单独存一份

如果当时直接跟着覆盖率一起"放宽"，会发生什么：
- 读数**不会变**（两种口径一致）；
- 但判据会被改写成"不限局"，**未来一旦行级 strict 字段的算法变化，就可能放进跨局的弱匹配**；
- 而且**没有任何收益**。

**这是一次"验证之后决定不改"的记录** —— 与 T246（排序停手）、Q18（默认关）、T267（净亏默认关）同一类：
**能证明"不需要改"的时候，就不要改。**

## 当前主判据（已正确）

| 指标 | 值 | 口径 |
|---|---|---|
| **严格命中** | **46.6%**（55/118） | 同局且满足严格条件（**两种定义一致，无需迁移**） |
| **覆盖率** | **79.7%**（94/118） | **内容相关（不限局）**（T362 已修正） |

## 复现

```bash
node -e "…（strictRow = r.strict||r.strictTokens||r.strictByBigramOnly，逐条比对 hitStrict）…"
# 输出：都命中 55 · 仅旧 0 · 仅新 0 · 都未命中 63
```
