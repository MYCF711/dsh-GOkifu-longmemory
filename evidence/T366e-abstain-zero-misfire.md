# T366e · 精化 + 跨语言修复后，abstain 在判据可靠的输入上**误杀率 = 0**（完整验证）

> 日期：2026-11-07 · 用真实考卷（n=118）+ 逐条人工核
> 结论：**在"判据可靠"的输入上，精化 + 跨语言修复后的 abstain **真误杀率 = 0%**（2 条被拒，**全部**是正确拒绝）。

## 一、完整验证（`scripts/abstain-effect-full.mjs`）

对考卷里**判据可靠**（`hasReliableHandle(signal)`）的题，
模拟"精化 + 跨语言"的 abstain：
- 卡上**没有** `bigramRaw ≥ 2` / `overlap ≥ 1` / **跨语言失败匹配** 的行 ⇒ 会被拒；
- **逐条核**被拒的题"卡上内容与信号是否真的无关"。

## 二、读数

```
判据可靠的题：59 / 118（50%）
精化 + 跨语言修复后，会被 abstain 拒掉的：2 条
```

**逐条核那 2 条**：

| 题 | 信号 | 卡上内容 | 判定 |
|---|---|---|---|
| `ep-1e976ca9` | "继续这个会话的任务" | `JSONDecodeError` / `tool call aborted` | **无关**（通用指令 vs 具体错误）⇒ **正确拒绝** |
| `ep-f46d6330` | "Codar科搭.exe 的模型版本" | `curl.exe not found` / `SyntaxError` | **无关**（别的工具的错误）⇒ **正确拒绝** |

⇒ **真误杀率 = 0%**（在判据可靠的输入上）。

## 三、与上一刀的对照

| 版本 | 会被拒的题数 | 真误杀率 |
|---|---|---|
| 精化前（词重合判据） | 3 | **33%**（`ep-75e7347e` 被误杀） |
| **精化 + 跨语言** | 2 | **0%**（`ep-75e7347e` 不再被拒，剩下 2 条都是正确拒绝） |

**跨语言修复把唯一的那条真误杀（`ep-75e7347e`）救回来了**：
`"安装失败"`（中文）与 `"Error: tool call aborted"`（英文）**讲的是同一件事**，
映射之后**不再被判为"不相关"**。

## 四、abstain 的"精化适用条件"现在长这样

```
判据可靠的输入（50%，有硬实体 / ≥2 英文判别词）
  ⇒ abstain **可用**，**误杀率 = 0**

判据不可靠的输入（50%，短指令 / 纯通用中文）
  ⇒ abstain **不启用**（保守，不误杀）
```

**这正是拉卡托斯的"精化适用条件"**：
**只在判据可靠的输入上启用** —— 而不是"全关"（blanket exclusion）。

## 五、重开条件的满足情况（对照 `docs/latent-toggles.md`）

| 重开条件 | 当前状态 |
|---|---|
| ① 被拒的**全部**不相关 | ✅ **满足**（2 条被拒，全部正确拒绝） |
| ② 注入率下降**全部**来自不相关 | ✅ **满足**（`ep-75e7347e` 的注入被救回，下降只来自"无关"的那 2 条） |
| ③ **误杀率 = 0**（逐条证据） | ✅ **满足**（在判据可靠的输入上，误杀率 = 0） |

**但注意**：这三条是在**"判据可靠"的 50% 输入上**验证的。
**"判据不可靠"的那 50%（短指令/纯通用中文）**，abstain **不启用**（保守）——
那部分**永远不会有误杀**（因为根本没启用）。

⇒ **abstain 现在可以在"判据可靠"的输入上开启了**（`abstainIrrelevant: true`）。

## 六、复现

```bash
node scripts/abstain-effect-full.mjs
# 判据可靠的题：59 / 118 · 会被拒 2 条
# 逐条核那 2 条：卡上内容与信号都无关 ⇒ 正确拒绝 ⇒ 真误杀率 = 0%
```

## 七、一句话

**"精化适用条件"让 abstain 在**它能判对的那一半**上真正可用了 —— 而在另一半（判据不可靠的输入）上，它**本来就不该启用**。
