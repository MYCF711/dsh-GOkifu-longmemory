## 2 · 配置（默认零配置，能跑就别动）

默认值（0.15 起）：`enabled:true`、`shadow:false`、`autoBuild:true`、`storeRoot:null`（= `<DSH_HOME>/memory-context`）。

| 键 | 默认 | 什么时候改 |
|---|---|---|
| `enabled` | `true` | 想完全停注入 ⇒ `false`（保留建库） |
| `shadow` | `false` | 只想观察、不注入 ⇒ `true`（写 `evidence/shadow/shadow.jsonl`） |
| `storeRoot` | `null` | 要把记忆库放到别处才填；支持 `$DSH_HOME` |
| `budgetTokens` / `limit` | `500` / `5` | 卡片太长/太少时调 |
| `repeatHint` / `repeatHintAfter` | `true` / `2` | D5 二次命中：同类失败 ≥N 次补一次卡 |
| `crossScopeClass` | `false` | **Q18 未裁定前不要开**：类级章节用跨项目先例（卡片标 `[跨项目]`） |

## 3 · 验证（装完看三样）

1. `install-doctor` 五项全 `ok`；
2. 当前库有数据：`node scripts/live-stats.mjs` 能看到心跳，或 `node scripts/cli.mjs stats` 显示局数与更新时间；
   （**本插件不提供设置页 UI**：只有 HTTP 配置路由 + 命令行；0.17 记录里的"设置页"已不适用，见 `evidence/M7-settings-ui-truth.md`）
3. 开一个新会话，做一件**与历史同类**的事，看是否出现 `<memory-ledger>` 卡片（首轮一次；D5 在同类失败 ≥2 次时补一次）。

D5 遥测（真注入后才会出现）：

```bash
node scripts/repeat-report.mjs    # 触发次数 / 涉及会话 / 类别分布 / token 均值
```

## 4 · 回滚（都在一分钟内）

| 想回滚到 | 怎么做 |
|---|---|
| 停注入、保留建库 | 设置里 `enabled:false` |
| 停影子 | `shadow:false` |
| 完全移除 | 设置 → 插件 → 移除；记忆库在 `<DSH_HOME>/memory-context`，需要时手动删 |
| 撤销 re-enable 的配置写入 | 同目录 `*.bak-reenable-<时间戳>` 覆盖回去即可 |

## 5 · 已知限制（不是故障）

| 现象 | 原因 |
|---|---|
| 很多会话零注入 | 主题/作用域不命中；**沉默是默认**（设计如此） |
| 卡里只有指针行 | claim 原文没过闸 3/5（validity/quote） |
| 定式永远 0 | 真实命令签名跨局不重复（`evidence/M5-joseki.md`，Q17） |
| A3 仍标 `not-live` | 只有**真实会话**注入后才变 live；`host-sim` 只给 simulated 证据 |

## 6 · 装完出问题怎么查

| 症状 | 先跑 | 再看 |
|---|---|---|
| 插件没出现 | `install-doctor` | 注册项：是否仍 `disabled: true`（说明第 ② 步没在退出 DSH 后执行） |
| 出现但从不注入 | `host-sim --store $DSH_HOME/memory-context` | `failed` 是否 0；`empty` 比例（沉默正常） |
| 卡片内容可疑 | `cli audit` / `cli facts --at <日期>` | 无支撑 claim 数、有效期是否止 |
| 指标掉下门槛 | `metrics-guard` | 输出里会给是哪一轴、差多少 |
