# 棋院（dsh-kifuin）安装指南

> **状态**：插件入口 `src/plugin.mjs` 已实现，**默认关闭**（`enabled:false, shadow:true`）。
> **安装由主人执行**：运行中不改 `profiles/*/cordis.patch.yml`、不重启 DSH（本机铁律）。

## 0 · 前置检查（agent 可代跑）

```bash
node scripts/check.mjs                 # 必须 PASS（退出 0）
node --test                            # 必须全绿
node scripts/archive.mjs               # 建库：默认 <DSH_HOME>/memory-context
node scripts/cli.mjs verify            # 必须 OK
node scripts/stage-check.mjs docs/staging/shadow.json   # 配置自检
```

库不存在时插件只 warn、不注入——**不会弄坏会话**，但也看不到效果。

## 1 · 怎么注册（缺这一步装不上）

DSH 的插件来自 **profile 的插件列表**（不是改 `cordis.patch.yml`）。两种方式任选其一，都走设置 UI：

1. **本地路径插件**：设置 → 插件 → 添加 → 选 `本地路径`，指向本仓库根目录（`package.json` 的 `name` 是 `dsh-kifuin`，`exports` 暴露 `./plugin`）。
2. **已发布的包**：本仓库**不发 npm**；如需远程安装，先用 `npm pack` 产出 tarball 再在设置里选本地 tarball。

注册后**先确认它被加载**：设置 → 插件列表里应出现 `dsh-kifuin`，状态为已启用但（按下面配置）不注入。

## 2 · 影子模式（建议先跑 1–2 天）

插件配置从设置 UI 填（JSON 形态）：

```json
{
  "enabled": false,
  "shadow": true,
  "storeRoot": null,
  "shadowDir": null,
  "budgetTokens": 500,
  "limit": 5,
  "oncePerSession": true
}
```

- `storeRoot: null` ⇒ 用 `<DSH_HOME>/memory-context`；也可以显式写 `<DSH_HOME>/memory-context`，插件会展开这个占位符（`$DSH_HOME` 同样支持）；**不要写别的相对路径**。
- `shadow: true` ⇒ **永远返回原 decision**，只把"本来会注入什么"追加到 `evidence/shadow/shadow.jsonl`（每行 `injected:false`）。
- `shadowDir: null` ⇒ `<repo>/evidence/shadow`；不允许落在 `$DSH_HOME` 内（硬守卫，拒绝时 0 字节写入）。

**验证影子在工作**：

```bash
tail -n 3 evidence/shadow/shadow.jsonl   # 每行是完整 JSON，injected:false
```

## 3 · 看影子数据（agent 可代跑）

```bash
node scripts/eval.mjs --h1 --store "<DSH_HOME>/memory-context" --workspace . --evidence evidence/M5-h1.md
node scripts/m5-report.mjs --store "<DSH_HOME>/memory-context" --workspace . --evidence evidence/M5-six-axis.md
```

看三件事：命中率（多少会话本来会注入）、token（p50/p95）、A1/A6 是否达标。

## 4 · 真注入（只在影子数据达标后）

```json
{ "enabled": true, "shadow": false }
```

- 行为：**每会话首轮**注入一次；卡片 = 固定一行 INDEX（约 35 tokens）+ 命中时展开（≤5 条、≤500 tokens）。
- 任何异常（库缺失/构建抛错/闸门不过/消息造不出）⇒ `logger.warn` + **原 decision**，不阻塞会话。
- 不写会话事件、不改会话日志；注入内容不进日志（只能从影子台账复盘）。
- 验证：开新会话看 messages 顺序（与压缩插件同点注入，两边都在"最后一条 claimed 之后"插入）。

## 5 · 回滚与卸载

- **停注入**：`enabled` 改回 `false`（保留影子可继续观察）。
- **完全卸载**：设置 → 插件 → 移除 `dsh-kifuin`；不会删任何会话日志或棋谱（记忆库在 `<DSH_HOME>/memory-context`，需要时手动删）。
- 回滚后 MemHook 不再被调用，零残留。

## 6 · 已知限制（不要当故障）

| 现象 | 原因 |
|---|---|
| 大部分会话零注入 | 语料属于别的工作区/主题不命中——**沉默是默认**（S9/S8） |
| 有命中但卡里只有指针 | claim 原文未通过闸 5（quote/seq）或闸 3（validity） |
| 定式永远 0 | 真实命令签名跨局不重复（`evidence/M5-joseki.md`，Q17 待裁定） |
| 影子文件里 `injected:false` | 影子模式定义如此 |
