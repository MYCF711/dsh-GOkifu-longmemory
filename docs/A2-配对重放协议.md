# A2 配对重放协议（T114 · 2026-11-04）

> 为什么要有这一页：六轴里 **A2（收益：不重复踩坑）是主判据**，但 `docs/对标-Hindsight.md` 至今只能写"不可比"——
> 对方没有同口径读数，我们也没有做"有记忆 / 无记忆"的配对比较。本协议把这件事变成**可以真的跑**的东西，
> 并且在跑之前先把**成本与判据**写死，避免"跑完再解释"。

---

## 1 · 判据（先写清楚，跑的时候不许改）

| 项 | 定义 |
|---|---|
| **单位** | 一个「重放任务」= 从**切点之后**的某一局里取一个**失败签名**（机械抽取，见 `src/rooms/extract.mjs`），还原成当时的用户输入 |
| **两个臂** | **有记忆（M+）**：先注入我们的卡片（`buildMemoryCard` 的实际产物），再让模型干活；**无记忆（M−）**：不注入任何东西，同样输入 |
| **结局** | 该任务是否**避免重蹈**那个失败签名（机械判定：重放后的事件流里不再出现同一签名；判据实现见 `src/rooms/sigindex.mjs` 的签名归一） |
| **主读数** | `Δ = P(避免 \| M+) − P(避免 \| M−)`，配对差（同一任务两臂都跑，做 McNemar 而非两独立比例） |
| **硬护栏** | ① 任务集**只用切点之后**的局（防"考同一张卷子"）；② 每对任务**同一模型、同一预算、同一提示模板**；③ 抽样必须**先冻结成文件**再跑（`evidence/a2-pair-set.json`），跑完不许换题；④ 出现 `Δ<0` 视为**负迁移信号**，与 A1 一起报，不许只报正的那部分 |

判读线（跑之前定，避免事后解释）：

- `Δ ≥ +10pp` 且 McNemar p < 0.05 ⇒ 记忆有可测净收益；
- `−10pp < Δ < +10pp` ⇒ 无差别，写"未测出收益"，不写"接近显著"；
- `Δ ≤ −10pp` ⇒ 记忆在拖后腿，先停注入排查。

## 2 · 成本估算（这是能不能跑的真正门槛）

- 每个任务 **2 次模型会话**（M+ / M−）；每次会话按 DSH 实测中位数 **~40 步**、每步 ~3k tokens 估：
  单次 ≈ 120k tokens ⇒ 单任务 ≈ **240k tokens**。
- 冻结集规模：**n=20 对**起步（McNemar 在 n=20 时只能检出 ≥40pp 的差异，所以 n=20 只够"抓大坑"，不够"证小胜"）。
  ⇒ **20 × 240k ≈ 4.8M tokens**。
- 要检出 10pp 级差异，按 McNemar 的近似功效估算需要 **n ≈ 80 对** ⇒ **≈ 19M tokens**。
- 这些全部是**真实模型调用**（不是零模型脚本）。本仓的既有约定是"读侧零模型调用"，所以这件事**必须主人点头**才跑：
  它不是技术选择，是**预算选择**。

## 3 · 执行形状（脚本骨架，先不接生产）

```
scripts/a2-pair-replay.mjs
  --set evidence/a2-pair-set.json   # 冻结任务集：{sig, scopeKey, episode, at, userInput, expectNoSig}
  --arm both|mem|nomem
  --out tmp/a2-replay/<runId>/      # 每次会话的原始事件落这里（不进 git）
  --dry-run                         # 只校验冻结集与成本，不调用模型
```

骨架必须做到：

1. `--dry-run` 能输出**任务数 × 每任务 token 估算 = 总成本**，与本文 §2 的数字对得上；
2. 每次会话把事件流落到 `tmp/`（不进 git），并用**同一份**签名归一逻辑判"是否重蹈"；
3. 结果落 `evidence/M8-a2-replay.md`：逐任务两臂结局表 + McNemar 检验 + Δ 与置信区间；
4. **两臂顺序随机化**（同一任务先跑哪臂要随机构造，避免系统时间对结果的影响）。

## 4 · 现在能不能跑

- 任务集已可机械产出（切点后 + 失败签名 + 用户输入还原），**不依赖模型**；
- 缺的只有两件：**① 主人对预算的表态**；② 运行侧要能起"干净会话"（不能用当前会话，否则两臂互相污染）。

在 ① 没给之前，本协议的产出就是这一页 + 一个 `--dry-run` 可用、`--arm` 拒绝执行的骨架。
这样下次接手不必重新想一遍，也不会有人误以为"随时能跑"。

## 5 · 与其它判据的关系

- **不能替代 A2b**：A2b 量"记忆有没有把当年那条错找出来"，A2 配对量"找出来之后有没有少踩坑"。两者都不过，谈"更强"都不成立。
- **不能替代 A1**：A1 量"错的东西进没进上下文"，配对重放若出现 `Δ<0` 要回到 A1 查是不是注入内容把模型带偏。
- **与 A5 联动**：配对集的每条任务都带 `scopeKey`；跨作用域的配对**必须单独分桶报**，不能混进主读数里。
