# 脱敏清单（公开仓库）

> 本仓库已公开；规则是"**结构留、标识去**"。CI 里的 `scripts/privacy-scan.mjs` 会拦回归。

## 已清掉

| 类别 | 处理 |
|---|---|
| 内网 IP（如 `192.168.x.x`） | → `<lan-ip>` |
| 本机用户目录（`C:\Users\<name>`） | → `<user-home>` |
| 密钥目录名（`X:\…Key`） | → `<key-dir>` |
| 本机绝对路径（`D:\…` / `E:\…`） | → `<workspace>` / `<DSH_HOME>` / `<upstream-repo>` |
| 真实会话 UUID | → `<session-id>`（测试夹具改用合成 id） |
| 真实棋谱 id（`ep-xxxxxxxx`） | → `<ep>` |

## 保留

- 设计文档里的**合成路径**（`d:/work/demo`）与合成 id（`session-aaaaaaa1-…`）——用于测试，不含真实数据。
- 开源依赖名、公开论文 URL、公开仓库名。

## 复跑

```bash
node scripts/privacy-scan.mjs          # 0 处 = PASS
node scripts/check.mjs                 # 已内置这条守卫
```
