# Q18 开闸设计（B 方案：类级章节跨工作区，标注 `[跨项目]`）

> 状态：**未开闸**（默认 A = 同作用域）。本文只写"开关怎么合、验收怎么判"，不改行为。
> 触发条件：主人在 `docs/拷问记录.md` 裁定 Q18=B。

## 1 · 开闸后要发生什么（行为契约）

- 跨工作区的 **class 级** claim 可以进入卡片，但**必须**带 `[跨项目]` 标记；
- 跨工作区的 **同域具体事实**（非 class）仍然不跨（避免把 A 项目的文件/命令当成 B 项目的先例）；
- 卡片行格式：`- [跨项目] [antipattern] class:xxx · …`（标记在 marker 之前，便于机械统计）；
- 作用域闸（A5）口径不变：**越界 = 0**；`[跨项目]` 条目单独计数 `crossScopeShown`，不算越界。
