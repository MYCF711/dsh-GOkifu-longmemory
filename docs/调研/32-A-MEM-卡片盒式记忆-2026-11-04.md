# A-MEM：Zettelkasten 式的动态组织记忆（2026-11-04 采集）

- 来源：[arXiv:2502.12110](https://arxiv.org/abs/2502.12110)（v11，2025-10-08；NeurIPS 2025）。
- [外] 卡片盒（Zettelkasten）原则：新记忆写入时生成**结构化笔记**（上下文描述、关键词、标签），
  再与历史记忆比对、**动态建立链接**；
- [外] **记忆演化（memory evolution）**：新记忆加入后，可以**回写更新旧记忆**的上下文表示与属性，
  让整张网持续精炼；
- [外] 六个基座模型上对比 SOTA 基线均有提升。

## 与我们对照

| A-MEM | 我们 | 判断 |
|---|---|---|
| 新笔记建属性 + 动态链接 | 归档时机械抽 claim/边，每条带 `why` | ✅ 同构（链接是核心） |
| **回写旧笔记**（记忆演化） | **只增不改**：新 claim + `supersededBy`，旧条原样保留 | ⚠ 红线分歧：他们靠回写提升精炼度，我们靠"保留原件 + 显式覆盖"保可回放 |
| LLM 生成笔记属性 | 机械抽取（无模型判断） | ⚠ 路线相反 |
| 评测在对话式基准上提升 | A2b 严格 89.5%（19 条冻结卷） | 口径不同，不可横比 |

## 两条可复用结论
1. **"写入时就建链接"比"批量后处理建链接"更省**：我们归档时同批建边，正是这个形状；
2. **回写是能力也是债**：A-MEM 的演化能持续精炼，但旧版被改掉后**无法回放"当时是怎么想的"**；
   我们的 `supersededBy` 方案牺牲一点精炼度，换 A6 可回溯 100% —— 这是有意识的取舍。

## 结论
无新机制可落地（回写旧记忆与"只增不改"冲突）；但它反证了我们的取舍是有代价、也有回报的：
代价是网络不会自动变"更聪明"，回报是每一条注入都能追到原始会话的 `ep+seq`。
