# 衰减 vs 冷却：记忆该"权重随时间降低"，不是"突然出现/消失"

> **范围**：只写"**衰减（连续权重）**"与"**冷却（二元开关）**"的关系 —— 记忆的真实行为是**随时间衰减**，而不是"突然出现/消失"。
> 不重复 `90-冷却优于先审再存`（主人纠正：不被调用就冷却）、`64-记忆的陈旧与过期`（stale 是条件变了，不是没人用）。
> 访问日期：2026-11-07。

## 为什么写这篇

上一刀我做了"冷却"（距最后注入 > N 天 ⇒ 不再出现）。
但那是**二元开关**（出现 / 不出现），而**记忆的真实行为是**随时间衰减**（权重逐渐降低）。

**"冷却"可以是"衰减到某个阈值以下 ⇒ 不再出现"**（衰减的特例），
但**"衰减"本身更有用**：**权重低的排在后面**，而不是"突然消失"。

## 一、判据（机械，已实现并测试）

`src/rooms/abstain.mjs` 的 `decayWeight(claim, now, { halfLifeDays })`：

```
以**最后一次被注入**（`lastInjectedAt`，无则用 `recordedAt`）为起点，
**权重 = 0.5 ^ (距今天数 / halfLifeDays)**（指数衰减，默认半衰期 **30 天**）。
**被调用时重置**（`lastInjectedAt` 更新 ⇒ 权重回到 1）。
```

**实测**（16 条测试全绿）：
| 距最后注入 | 权重 |
|---|---|
| 刚被调用 | **1** |
| 30 天（一个半衰期） | **0.5** |
| 60 天（两个半衰期） | **0.25** |
| **30 天前入馆但**昨天被调用** | **≈ 1**（**被调用时重置**） |

## 二、衰减 vs 冷却：不是替代，是包含

| | 冷却（二元） | **衰减**（连续） |
|---|---|---|
| 形态 | **出现 / 不出现** | **权重 0..1，随时间降低** |
| 用途 | **"不再出现"** | **"权重低的排在后面"** |
| 关系 | **"冷却"是"衰减到阈值以下 ⇒ 不再出现"**（衰减的特例） | **衰减是更一般的机制** |

**"冷却"是"衰减到某个阈值以下 ⇒ 不再出现"** —— 与"按衰减权重排序"**配合使用**：
- **权重高的排前面**（最近被调用的）；
- **权重低的排后面**（很久没被调用的）；
- **权重低于阈值 ⇒ 不再出现**（**冷却**）。

## 三、对本仓的落地

### ① **按衰减权重排序**（权重低的排在后面）
在 `buildMemoryCard` 的排序里，把 `decayWeight` 作为**排序因子**之一：
**最近被调用的排前面，很久没被调用的排后面** —— 而不是"按入馆时间排"（入馆时间不代表"有用"）。

### ② **"冷却" = "衰减到阈值以下 ⇒ 不再出现"**
`isCold`（已实现）是**二元**的（距最后注入 > N 天 ⇒ 冷却）。
**"衰减"更细**：**权重 < 0.1（比如 3 个半衰期）⇒ 不再出现** —— 与"排序"配合，**权重低的自然沉底**。

### ③ **"被调用时重置"是关键**
**一条记忆被调用 ⇒ `lastInjectedAt` 更新 ⇒ 权重回到 1** ——
**"有用的记忆不会衰减"**（它一直被调用，所以一直"新鲜"）。
**只有"不被调用"的记忆才会衰减到"冷却"**。

## 四、与前几篇的关系

- **90（冷却优于先审再存）**：主人纠正"不被调用就冷却" —— 本篇把"冷却"**升级为"衰减"**（连续权重）；
- **64（记忆的陈旧与过期）**：`stale` 是"**条件变了**"（过期），**"衰减"是"**没人用**"（冷却）—— **两个维度要分开**：
  - **"过期"**：条件变了（`validTo` / `preconditions`）；
  - **"衰减"**：**没人用**（`lastInjectedAt` 距今）。
  **一条记忆可以"没过时但没人用"（衰减），也可以"有人用但已过时"（stale）**。

## 五、一个我不会做的事

**不会**把"衰减"当成"删除"的借口 —— **衰减只是"权重降低、排在后面"，不是"从库里抹掉"**。
**原件永不删**（本仓纪律）；**"衰减到冷却"也只是"不再出现"，不是"不存在"**。

## 六、一句话

**"冷却"是"不再出现"，而"衰减"是"权重随时间降低、排在后面" —— 后者更接近记忆的真实行为，而且**被调用时重置**，所以**有用的记忆永远不会衰减**。**
