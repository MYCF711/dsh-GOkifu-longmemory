# 记忆系统机制速览（外部资料，2026-11-02 采集）

> 只记「读了什么、它怎么做的、对我们有什么用」。**外部结论一律标 [外]**，本仓实测标 [本]。
> 采集方式：arXiv abs 页 / GitHub README（web_search 端点当前不可用，见 §5）。

## 1 · A-MEM（Agentic Memory，NeurIPS 2025）

- 来源：[arXiv:2502.12110](https://arxiv.org/abs/2502.12110)（v11，2025-10-08）；代码 `WujiangXu/A-mem-sys`。
- [外] 机制：
  1. **Zettelkasten 式笔记**：新记忆入库时生成结构化属性（上下文描述、关键词、标签）。
  2. **动态索引与连接**：与历史记忆比对，相似则建链；形成互连知识网络。
  3. **记忆演化（memory evolution）**：新记忆会触发**旧记忆**的上下文表示/属性更新，网络持续精化。
  4. 六种基座模型上优于既有 SOTA。
- 对我们的映射：我们的 `claimEdge`（corroborates/contradicts/supersedes/derives）是静态边；**缺"新条目触发旧条目属性更新"**。
- 可借鉴（不越界）：新 claim 入库时，只更新**旧的同类 claim 的 `validTo`/`supersedes` 指针**（结构变更只增不改），不重写文本。

## 2 · Zep / Graphiti（时序知识图谱）

- 来源：[arXiv:2501.13956](https://arxiv.org/abs/2501.13956)（2025-01-20）。
- [外] 机制：
  1. **时序感知知识图谱**：边带有效时间，保留历史关系（而非覆盖）。
  2. 同时吸收非结构化对话 + 结构化业务数据。
  3. DMR 94.8% vs MemGPT 93.4%；LongMemEval 提升最高 18.5%，延迟降 90%。
  4. 强项：跨会话信息综合、长期上下文维护。
- 对我们的映射：我们已有 `occurredAt/recordedAt` 双时钟、`supersedes`、`validityOk`；**缺边的 `validFrom/validTo`**。
- 可借鉴：claimEdge 加 `validFrom/validTo`（双时态），用于"这条结论当时有效、现在失效"的时间线查询；与我们「只增不改 + supersedes」一致。

## 3 · Mem0（2025-04 论文 + 2026 新一代算法 README）

- 来源：[arXiv:2504.19413](https://arxiv.org/abs/2504.19413)（引用见 README）；[github.com/mem0ai/mem0](https://github.com/mem0ai/mem0)。
- [外] 新一代算法（README「What changed」）：
  1. **单遍 ADD-only 抽取**：一次 LLM 调用，无 UPDATE/DELETE；记忆累积、不覆盖。
  2. **Agent 生成事实一等公民**：agent 确认过的动作与其它事实同权重。
  3. **实体链接**：抽取实体、嵌入、跨记忆链接以提升召回。
  4. **多信号检索**：语义 + BM25 关键词 + 实体匹配并行打分后融合。
  5. **时序推理**：按日期排序，区分「当前状态/过去事件/未来计划」。
- [外] 自报基准：LoCoMo 92.5、LongMemEval 94.4、BEAM(1M) 64.1；token 6–7K、p50 ~1s。
- 对我们的映射：
  - 「ADD-only」= 我们的只增不改 ✅；
  - 「agent 确认的事实一等公民」= 我们的 L4 人纠错 + 成功边 ✅；
  - 「多信号检索」我们只有 topic/error-class 单一通道，**缺关键词通道**；
  - 「时序推理」我们有 occurredAt 排序，但**没有"当前/过去/未来"三分**。
- 可借鉴：加 BM25 关键词通道（纯文本、非向量），与主题通道融合；卡片按「当前状态 vs 历史」标注。

## 4 · 与我们边界的冲突（明确不做）

| 外部做法 | 为什么不做 |
|---|---|
| 嵌入/向量检索（Mem0 语义通道） | `docs/记忆的职责边界.md` 禁止向量检索；且我们面向模型、token 预算小 |
| 图数据库（Neo4j 等） | sidecar JSON + 索引足够；部署重量与单机目标不符 |
| LLM 抽取事实（Mem0 的 LLM 调用） | 「禁止从摘要再抽取」+ 成本不可控；我们只做机械抽取 |
