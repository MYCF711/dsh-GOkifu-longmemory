# 考卷自己就是 bug：测试工具的债（2026-11-06 采集）

- 来源：一手文档（已读全文，访问日期 **2026-11-06**）：
  [PIT · Weak tests](https://pitest.org/weak_tests/)。
- **范围声明**：56 篇讲**考卷污染**（题目本身坏）、61 篇负向对照、65 篇变异测试、66 篇幂等、70 篇 Goodhart；
  本篇只写**"测量工具自己出 bug"**——harness 债的形态、可信判据、上线门。五篇不重复页面。

## 一、最危险的假绿：满覆盖 + 什么都没测

- [外] **无断言也能满分支**："It's easy to see how a test with **no assertions** can generate **full branch
  coverage** without meaningfully testing the code it executes."
- [外] **"表面良好"更隐蔽**："It can be **less obvious** how **superficially good tests** can fully execute code
  without fully testing it. The simple explanation is that the suite has **missing test cases**."
- [外] **量化陈述**："In most cases the tests that have been written are sufficient to generate **100% branch
  coverage**, but **the code can be mutated such that its functionality is changed but all tests still pass**."
  ⇒ **覆盖率是对 harness 的夸奖，不是对产品的**。
- [外] **债是人为的**："It is also easy to understand how **uses tests** are written due to **human error** — e.g.
  programmers used to a mocking framework that **does not distinguish between stubbing and verification**
  forgetting to write verification steps when switching to one that does."
  ⇒ **换工具/换环境时，判据会悄悄消失**——这正是我们"后续任意 exit 0"的同型。

## 二、harness 债的三种经典形态（PIT 命名）

| 形态 | 症状 | 机制 |
|---|---|---|
| **The untested side effect** | 只断言返回值，**从不检查副作用被调用** | 分支全绿，但"该发生的事"没验 |
| **The missing boundary test** | 测了 `1` 与 `-1`，**`i == 0` 从未测** | 边界缺失，改坏 `>=`/`>` 不红 |
| **The myopic mockist** | 只 `verify` 交互，**从不检查返回值** | 反向的盲区（验了调用，没验结果） |

**共同点**：三种的**覆盖率都好看**，因为它们都在"**执行**"代码，而没在"**检查**"结果。

## 三、"考卷可不可信"的机械判据（五条）

| # | 判据 | 检查 | 不过关的含义 |
|---|---|---|---|
| **Q1 输入钉住** | 跑之前**固定输入**（`at` / `claimsCount` / `signal` / 随机种子 / 语料版本） | 两次跑输入哈希相同 | **不可复算**（本仓第 5 次事故：48.25% 没钉住输入） |
| **Q2 负向对照** | 在"不该命中"的样本上跑同一条管线，误判率不升（61 篇） | 升 ⇒ 造命中 | 提升是假的 |
| **Q3 判据作用域** | 判定**只认该管的字段**（不看整段 blob、不看退出码以外的旁路） | 作用域写死 | 93.71% 那类："整段命中即算 + 后续任意 exit 0" |
| **Q4 边界与副作用** | 至少一条**边界**（=`0`/空/首尾）与一条**副作用**断言 | 改 `>=`→`>` 必须红 | 缺测（PIT 三种形态） |
| **Q5 可复算** | 换实现/换人重算一致（construct validation，70 篇 V3） | 一致 | 测错对象 |

**五条全过才叫"可信的考卷"**；Q1 是地基（没钉住输入，后面全无意义）。

## 四、可执行检查：一份考卷上线前的门

```
G1 钉输入：at / claimsCount / signal / 种子 / 语料版本 全部写死在快照里
G2 双跑：两次输出逐字节相同（66 篇 I1）
G3 负向：不该命中的样本上误判率不升
G4 边界+副作用：改 >=→> 必须红；副作用必须有断言
G5 作用域审查：判据只看该管的字段（禁止 blob/旁路）
G6 tombstone：故意改坏一条（seq+4 / 恒等式差 5）必须红（65 篇）
```
**六道全过**才许进"验收面"；Q1 不过 ⇒ 结果连"观察"都不算。

## 五、对照本仓（棋院，写作时点实测）

今天五次"测量工具错了"，逐条对上第二节/第三节：

| 次 | 数字 | 形态 | 命中判据 |
|---|---|---|---|
| 1 | 94.7% | 只考容易题（**missing test cases** 的变体：缺题型） | Q2/Q5 |
| 2 | 41.67% | 用答案当线索（**untested side effect** 的变体：输入混入答案） | Q1 |
| 3 | 50.88% | bigram 泛词伪命中（**myopic**：只看重叠，不看语义） | Q3 |
| 4 | 93.71% | 整段 blob 判失败 + 后续任意 exit 0（**判据作用域过宽** + **换工具后判据消失**） | Q3 |
| 5 | 48.25% | **没钉住 `at` / `claimsCount` / `signal`** | **Q1** |

**五次没有一次是产品变好**；**唯一真实提升是"把尺子修对"（+14.04pp）**。
**本仓的 harness 债**：Q1（输入钉住）与 Q6（tombstone 自动化）**都没有门禁**——
所以第五次事故（48.25%）随时能重演。

## 结论

判据三句话：**满覆盖也可能是假绿**（PIT：100% 分支 + 功能被改而测试全过）；
**harness 债有三种经典形态**（未测副作用 / 缺边界 / 只验交互不验结果）；
**可信考卷 = Q1 输入钉住 × Q2 负向 × Q3 作用域 × Q4 边界副作用 × Q5 可复算**。
最后一句：**五次事故都是"测量工具错了"，而工具的错误不会自己报警**——
除非你**先钉住输入，再故意把它改坏**（Q1 + Q6）。
