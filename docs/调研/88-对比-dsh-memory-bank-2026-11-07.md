# 对比 `morning-start/dsh-memory-bank`：写入面"先审再存" vs 我们的读面"不相关时沉默"

> **范围**：对比 `morning-start/dsh-memory-bank` 与本仓，蒸馏出**能吸收的机制**（不是泛泛的"更好"）。
> 依据：该仓库的 `README.md`、`docs/02-设计.md`、`docs/03-审核协议.md`（访问日期：**2026-11-07**）。
> 访问日期：2026-11-07。

## 一句话对比

**dsh-memory-bank 做"写入面"**（先审再存，十道门），**本仓做"读面"**（顺藤摸瓜，不相关时沉默）。

**两者共享同一条原则**：
- 他们："协议是**确定性**的，**不调用模型**"（纯算术，可复现）；
- 我们："**计数不是打分**"（`AGENTS.md` §2.3，禁止模型评分参与晋升、排序、存留）。

**所以他们的机制几乎都能直接吸收**（判据形态一致，不是另一套哲学）。

## 他们的核心（一手引文）

### [外 1] 判定先于存储
> "**判定先于存储。** 存储是廉价的，判定是稀缺的。**插件 80% 的价值在「不记」。**"
> — `docs/02-设计.md`

### [外 2] 十道门（先审再存）
> "**让「不记」成为默认结果，让「记」必须赢得它。**"
> 7 道硬门（归属/形态/安全/注入/证据/重复/配额）+ 3 道软门（草稿/冲突/置信）。
> — `docs/03-审核协议.md`

### [外 3] 三级交付
> "有把握给正文，没把握给**指针**，无关就 **abstain** 并说出**拒的是哪道门**。"
> — `README.md`

### [外 4] 漂移的两态
> "目标**消失** = `quarantined`；目标还在但**切片变了** = `advisory`（**重构不是攻击**）。"
> — `README.md`

### [外 5] 不做语义去重（实测做不到就明说）
> "**不做语义去重**（v1）。通道实现好了，但本地实测分离度 **−0.020 ~ +0.063**
> （同一批候选，改几段文档就翻号），**连开闸线都够不到**。"
> — `README.md`

## 六个能吸收的点（按可操作性排序）

### ① **三级交付的"指针"这一级**（content / pointers / abstain）
- **他们**：拿不准就**给指针**（不给全文）。
- **我们**：有命中给全文（**没有"指针"这一级**）。
- **可吸收**：**"拿不准时给指针"** —— 指针**更省 token 且不会误导**（模型自己去查，而不是被全文带着走）。
- **我们已经有 `[stale]` 只给指针**（T165）—— **可以推广**：**"不确定时给指针"**（不只 stale）。

### ② **abstain 时"说出拒的是哪道门"**（可解释的拒绝）
- **他们**：`abstain` 并**说明"拒的是哪道门"**。
- **我们**：`abstain` 的 `reason = 'no-relevant-claim'`（我刚加的）。
- **可吸收**：**拒绝时给出具体判据**（"没有与信号相关的行" / "跨作用域" / "过期"）—— **让"没给"变得可解释**。
- **价值**：模型知道"**为什么没给**"，**该去查什么**（而不是"什么都没有"）。

### ③ **漂移的两态**：目标消失 vs 切片变了
- **他们**：目标**消失** = `quarantined`；**切片变了** = `advisory`（**重构不是攻击**）。
- **我们**：`stale`（条件已变）。
- **可吸收**：**"切片变了"不该当成"失效"** —— **重构不是攻击**。
- **我们的 `stale` 判据可能把"重构"误判为"失效"** —— **代码重构后，记忆仍然有效，只是位置变了**。

### ④ **写入面的"先审再存"**（十道门）—— ⚠ **已被主人 2026-11-07 纠正，见知识库 90**
- **他们**：**先审再存**（写入面的质量控制）。
- **我们**：**没有写入面的审核**（库里有 1543 条 claim，其中很多噪声）。
- ~~可吸收：写入面的审核~~ → **主人纠正**：**"记忆该不该存不是写入的时候决定的，而是写入后是否被调用，不被调用就冷却，等于没写"**。
- **"先审再存"会误杀"将来有用"的记忆**（写入时无法预知"有没有用"）。
- **真正该吸收的不是"先审再存"，而是"**冷却**"** —— **长期不被调用的记忆，不再出现在上下文**（**等于没写，但不删**）。
- **"归并"是正常行为**（整理，不是拒绝）。
- **详见知识库 90《冷却优于先审再存》。**

### ⑤ **"失败必须可见"**（每次写入含被拒都进 ledger）
- **他们**：**每一次写入尝试（含被拒）都进 `ledger.jsonl`** —— "**静默失败比不记忆更糟**"。
- **我们**：心跳（`live-stats.jsonl`，记录 inject/skip）。
- **可吸收**：**"被拒的也要记"** —— 我们的心跳记录了 skip，但**没有记录"为什么被拒"的完整信息**（哪道门、什么理由）。
- **价值**：**被拒的记录是"哪里出了问题"的最直接证据**（我们的 `gates-failed` 只有计数，没有明细）。

### ⑥ **"实测做不到就明说"的态度**（语义去重的分离度）
- **他们**：实测发现语义分离度 **−0.020 ~ +0.063**（连开闸线都够不到），就**明说"不做"**。
- **我们**：也用机械判据（没有硬上语义/向量）。
- **可吸收**：**这种"实测做不到就明说"的态度** —— 他们**真的去测了**，发现不行，就**不做**（而不是硬上）。
- **这与我们的"默认关"是同一个精神**：**证据不够就不上**。

## 我们比他们强的一点（不妄自菲薄）

**读面的"不相关时沉默"，他们没有那么强调**：
- 他们的重点是"**先审再存**"（写入面），**召回是"三级交付"**（content / pointers / abstain）；
- 我们的重点是"**顺藤摸瓜 + 不相关时沉默**"（读面），**召回的判据更细**（内容相关 + 方向一致 + 跨语言失败映射）。
- **我们的"相关但反向"检测（`polarity`）他们没有** —— 那是"**给了反而误导**"的防线，**比"给不给"更细**。

**所以不是"他们更好"，而是"**两端互补**"**：
- **写入面**（他们）：**先审再存**，别存坏的；
- **读面**（我们）：**不相关时沉默 + 反向不误导**，别给坏的。

## 可执行的下一步（**未实施，需裁定**）

按"最小交付房间"原则，**一次只吸收一条**：

1. **先做"abstain 时说出拒的是哪道门"**（②）—— **改动最小、最可验收**：
   把 `abstain` 的 `reason` 从单一的 `no-relevant-claim` 扩成**按判据分类**
   （`no-relevant-claim` / `cross-scope` / `stale` / `low-confidence`），
   **并在卡片上说明"为什么没给"**（让模型知道该去查什么）。

2. **再做"三级交付的指针这一级"**（①）—— **"拿不准给指针"**：
   在 `confidence` 不足时，**给指针（`[observed]` + `seq`）而不是全文**。
   **我们已经有 `[stale]` 只给指针**（T165），可以推广为"**不确定时给指针**"。

3. **最后评估"写入面的先审再存"**（④）—— **那是另一条线**（写入面），
   需要先看"我们的库到底存了多少噪声"（如果噪声多，**写入面的审核**价值就大）。

**每条都可独立验收**，不要一次全上。
