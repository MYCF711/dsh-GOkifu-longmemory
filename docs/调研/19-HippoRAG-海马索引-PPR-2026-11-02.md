# HippoRAG：海马索引理论 + 知识图 + Personalized PageRank（2026-11-02 采集）

- 来源：[arXiv:2405.14831](https://arxiv.org/abs/2405.14831)（v3，NeurIPS 2024）。
- [外] 灵感来自**海马索引理论**：大脑长期记忆靠"新皮层存表征 + 海马存索引"协同；
  它用 **LLM + 知识图 + Personalized PageRank（PPR）** 模拟这两个角色。
- [外] 自报结果（多跳问答）：
  - 比现有 RAG 方法最高 **+20%**；
  - **单步检索**即达到或超过 IRCoT 这类迭代检索，同时便宜 **10–30×**、快 **6–13×**；
  - 与 IRCoT 结合还能进一步提升。

## 与我们对照

| HippoRAG | 我们 | 判断 |
|---|---|---|
| 知识图（实体/关系） | `topics` + `links` + `threads`（机械计数、带 why） | ✅ 同构 |
| 海马"索引" | `walk` 顺藤摸瓜（≤2 跳，沿边） | ✅ 同构 |
| **PPR 排序**（沿图做全局概率扩散） | **没有**：我们是"跳数上限 + 机械权重"的局部扩散 | ⚠ 差异点 |
| 单步替代迭代检索 | 我们本来就单步（一次 pre-step 一张卡） | ✅ 同路线 |
| 成本优势 | p50 ≈2ms、tokens p50 248 | ✅ 同量级目标 |

## 唯一值得考虑的实现（候选，不擅自做）
把 `walk` 的扩展顺序从「BFS ≤2 跳」改成「**带衰减的推式扩散**」（PPR 的 10 行近似）：
每跳权重 ×(1−α)，同一节点被多条路径命中则累加。
- 性质：纯机械计数（允许——不是模型打分）；
- 风险：会改变卡片条目排序 ⇒ 必须用 **A2b 严格 + hopPrecision（S0/S1）** 前后对照，任一掉就回退；
- 目前**不做**：现有 A2b 已 84.2%（剩余一次性错误），PPR 的收益无从验证，先记为候选。

## 结论
HippoRAG 印证"图 + 索引"的大方向没错；它比我们多的是 PPR 全局扩散，少的是作用域闸与十道闸。
**没有需要立刻实现的机制**；PPR 列为 N3 候选（需精度抽样前提）。
