# Reflexion：用"言语反思"代替权重更新（2026-11-03 采集）

- 来源：[arXiv:2303.11366](https://arxiv.org/abs/2303.11366)（v4，2023-10-10）。
- [外] 核心：不改权重，而是让 agent 对任务反馈做**言语反思**，把反思文本放进**情景记忆缓冲**，
  下一次尝试时基于它做决策。
- [外] 反馈可以是标量也可以是自由文本，来源可外部可内部模拟。
- [外] 在 HumanEval 上 pass@1 **91%**（当时的 GPT-4 是 80%）；在顺序决策、语言推理等任务上同样显著优于基线。
- [外] 作者还做了消融：反馈信号类型、反馈注入方式、agent 类型都会影响效果。

## 与我们对照

| Reflexion | 我们 | 判断 |
|---|---|---|
| 反思由**模型**生成（自然语言总结） | 反思由**机械抽取**生成（错误原文 + 类归并 + claim） | ⚠ 方向相反：我们刻意不调模型 |
| 反思进情景记忆缓冲，下次尝试读取 | 失败教训进 claim，新会话命中时注入卡片 | ✅ 结构同构 |
| 反馈驱动"下次更好" | 我们的验收是"不重复踩坑"（六轴） | ✅ 目标一致 |
| 反思质量依赖模型 | 反思质量依赖**抽取规则**（可单测、可审计） | ✅ 更可复核，但语义浅 |
| 不更新权重 | 不更新任何模型 | ✅ 同 |

## 关键差异（值得记下）
Reflexion 的反思是"**模型对自己说的话**"；我们的反思是"**日志里真实发生的事**"。
前者更会总结、更容易迁移，但**可能总结错**；后者更笨、更啰嗦，但**每一条都能回放**（episode + seq）。
这正是本项目在边界成文法里选的路线：宁可注入笨事实，不注入聪明摘要。

## 可复用的一条
"**反思必须回到下一次决策里，否则等于没反思**"。
我们的对应物是 D5（同类失败 ≥2 次补一次事实卡）——它存在的意义就是把"这次踩的坑"在同会话内再喂回去。
（D5 已在 0.68.0 收口，有闸内单测。）

## 结论
无新机制可落地（模型反思被边界禁止）；本文给了一条**设计正当性**：
把失败教训持久化并在下次决策前取出，是经过实验验证有效的路线，而我们的实现只是把"模型生成"换成"机械抽取"。
