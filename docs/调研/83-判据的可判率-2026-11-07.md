# 判据的可判率：一个判据"能判多少"，决定它的结论有多可信

> **范围**：只写"**可判率（decidability / coverage）**"这一面 —— 一个判据在多少样本上能给出明确判定，以及为什么"可判率太低 ⇒ 结论不可用"。
> 不重复 `79-不相关时沉默`（选择性预测的风险/覆盖交换）、`46-三值逻辑`（未知怎么传播）、`50-判据总表`（指标怎么定）、`80-判据校准`（阈值怎么定）。
> 访问日期：**2026-11-07**。

## 为什么写这篇

今天我给自己的 `detectPolarity`（方向判据）算了一个"反向记忆率 = 1.1%"，看起来**达标**（<5%）。

但紧接着发现：**190 对里只有 7 对判出了方向（3.7%）**，其余 183 对都是 `unclear`。

⇒ **那个 1.1% 是在 3.7% 的样本上算出来的，它几乎不说明问题。**

**我差点把"可判的那一小撮的读数"当成"全体的读数"。**
这篇把"**可判率**"作为一个**必须同时报告**的量写下来。

## 一、一手文献

### [外] 选择性预测里，"覆盖率"与"风险"是**一对必须同时报**的量
Geifman & El-Yaniv《Selective Classification for Deep Neural Networks》（2017）：
> "Our method allows a user to set a **desired risk level**. At test time, the classifier **rejects instances as needed,
> to grant the desired risk**."
> "an unprecedented **2% error** in top-5 ImageNet classification can be guaranteed with probability 99.9%,
> and almost **60% test coverage**."
>
> — https://arxiv.org/abs/1705.08500 （访问 2026-11-07）

**注意它报的是两个数**：**2% error（风险）** 与 **60% coverage（覆盖）**。
**只说"2% 错误率"而不说"只在 60% 的样本上"，就是在误导。**

⇒ 这与本仓的"反向记忆率 = 1.1%（但只在 3.7% 的样本上）"是**同一个陷阱**。

## 二、对照本仓：我的"反向记忆率"是在 3.7% 的样本上算的

| 量 | 值 | 说明 |
|---|---|---|
| 反向记忆率 | 2/190 = **1.1%** | 看起来**达标**（<5%） |
| **可判率** | 7/190 = **3.7%** | **只有 3.7% 的对能判出方向** |
| **在可判的那部分里** | 2/7 = **28.6%** | **真实的风险集中在这一撮** |

**三个数讲三个不同的故事**：
- 只说 1.1% ⇒ "**没问题**"（误导）；
- 只说 28.6% ⇒ "**问题很大**"（以偏概全）；
- **三个一起说** ⇒ "**能判的那部分里有 28.6% 是反向的，但 96.3% 判不了，所以全体是多少我不知道**"（**诚实**）。

## 三、机械判据（可执行）

### 判据 1：任何"率"都必须**同时报可判率**
```
报："反向记忆率 1.1%（可判率 3.7%，n=7/190）"
不报："反向记忆率 1.1%"   ← 省略可判率 = 误导
```

### 判据 2：可判率**低于阈值**时，**结论标记为"不可用于决策"**
```
可判率 < 30% ⇒ 该读数只能作为"**局部观察**"，**不能**作为"全体达标/不达标"的判据。
```
（30% 是经验阈值，**不是标准**；核心是**必须有一个阈值，而不是没有**。）

### 判据 3：**unclear 必须单列**，不许并进"没问题"
```
same / opposite / unclear 三类**分开计数**；
**绝不**把 unclear 算进 same（= 把"判不了"当"没问题"），也**绝不**算进 opposite（= 把"判不了"当"有问题"）。
```

### 判据 4：**提高可判率**比"把判据调得更严"更重要
一个只在 3.7% 上有效的判据，**再准也没用**。
**先扩判据的覆盖面**（让更多的样本能被判），**再谈精度**。

## 四、我今天的具体教训

我写 `detectPolarity` 时，只覆盖了"**关掉 vs 更频繁**"这一种反向形态。
⇒ **可判率只有 3.7%**（绝大多数 claim 没有明显的"方向词"）。

**正确的做法**（**未实施**）：
1. **先量可判率**：这个判据在多少样本上能给出明确方向？（我：3.7%）
2. **如果可判率太低** ⇒ **承认"这个判据目前不能用来评估全体"**，而不是拿它的小样本读数去下结论；
3. **扩判据**（更多的方向词、反例标记、人工标注）**先把可判率提上去**，**再谈反向率**。

## 五、与知识库其它篇的关系

- **79（选择性预测）**：风险与覆盖**交换** —— 本篇是它的**另一面**：**覆盖率本身就是结论可信度的前提**；
- **46（三值逻辑）**：`unknown` 怎么传播 —— 本篇给出**"unknown 有多少"必须报告**的判据；
- **50（判据总表）**：指标怎么定 —— 本篇补上"**每个指标都必须带可判率**"；
- **80（判据校准）**：阈值怎么定 —— **可判率太低的判据，没有资格被校准**（先扩覆盖面）。

## 六、一句话

**"这个判据说没问题"和"这个判据只在 3.7% 的样本上说没问题"，是两句完全不同的话。**
