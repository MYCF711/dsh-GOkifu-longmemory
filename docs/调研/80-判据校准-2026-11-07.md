# 判据校准：阈值不是拍出来的，是按"目标误杀率"反推的

> **范围**：只写"**一个判据/阈值怎么校准**"这一面 —— 校准（calibration）、目标误杀率反推阈值、以及"误杀率 = 0"该怎么证。
> 不重复 `50-判据总表`（指标怎么定）、`56-考卷污染`（尺子错了怎么办）、`65-变异测试`（测试有没有效）、`79-不相关时沉默`（什么时候该拒绝）。
> 访问日期：**2026-11-07**。

## 为什么写这篇

本仓现在的几个关键阈值**都是拍脑袋定的**：
- `bigramRaw ≥ 2` 算"相关"；
- `overlap ≥ 1` 算"硬实体命中"；
- abstain 的"≥2 判别词 或 ≥1 硬实体"。

**每一个我都答不上来："这个阈值对应的误杀率是多少？"**

今天 abstain 默认关，就是因为我**无法证明"误杀率 = 0"**。
这篇把**校准**的一手文献搬过来，给出"**怎么把误杀率测出来、怎么按目标误杀率反推阈值**"的机械方法。

## 一、一手文献

### [外 1] 校准 = 预测的概率与真实正确率一致
Guo / Pleiss / Sun / Weinberger《On Calibration of Modern Neural Networks》（ICML 2017）：
> "Confidence calibration -- the problem of predicting probability estimates
> **representative of the true correctness likelihood**."
>
> — https://arxiv.org/abs/1706.04599 （访问 2026-11-07）

**对本仓的含义**：判据说"这条与信号相关"，**它有多大概率是对的？**
如果判据是校准的，那么"判为相关的 100 条里，应该有 X 条真相关"，而 X 是**可测的**。

### [外 2] 模型（和判据）常常是**不校准**的
同文：
> "We discover that modern neural networks, unlike those from a decade ago, are **poorly calibrated**."

⇒ **"判据判为相关" ≠ "真的相关"**，而且偏差往往不小。
**不测量就不知道差多少。**

### [外 3] **单参数**校准就足够
同文：
> "on most datasets, **temperature scaling** -- a **single-parameter** variant of Platt Scaling --
> is **surprisingly effective** at calibrating predictions."

⇒ **不需要复杂模型**：**一个阈值参数**，按真实分布调一下，就能显著改善。
**我们的阈值就是那个"单参数"。**

## 二、对照本仓：我们的阈值是"未校准"的

| 阈值 | 现在的来源 | 缺什么 |
|---|---|---|
| `bigramRaw ≥ 2` | **拍脑袋** | 这个阈值对应多少**误杀率**（把真相关的判成不相关）？ |
| `overlap ≥ 1` | **拍脑袋** | 对应多少**误判率**（把不相关的判成相关）？ |
| abstain 的判据 | **拍脑袋** | **误杀率 = 0** 该怎么证？ |

**没有校准 ⇒ 我无法回答"这个判据有多可靠" ⇒ 不敢在生产里用它去拒绝。**

## 三、机械方法：怎么把"误杀率"测出来

### 步骤 1：先有一个**标注集**
取一批 `(信号, claim)` 对，**人工标注**"相关 / 不相关"。
**没有标注集就没有校准**（这是硬前提）。

规模建议：**≥100 对**，其中**真相关与真不相关都要有足够样本**（否则误杀率/误判率测不准）。

### 步骤 2：算出每个候选阈值的两个率
对每个候选阈值 `T`（如 bigramRaw ≥ 1、≥2、≥3…）：
```
误杀率(T) = 判为"不相关"但**真相关** 的条数 / 真相关总条数      （漏放）
误判率(T) = 判为"相关"但**真不相关** 的条数 / 真不相关总条数    （误放）
```
**两个率必须分开算** —— 它们的代价**不对称**。

### 步骤 3：按**目标误杀率**反推阈值（而不是拍）
```
选 T* = min{ T : 误杀率(T) = 0 }      # 一个都不许误杀
再看 误判率(T*) 是多少 —— 如果太高，说明**没有"零误杀又高效"的阈值**，那就该**默认关**。
```

**这才是 abstain 重开的正确路径**：
> 不是"感觉误杀率 = 0"，而是**在标注集上测出"阈值为 T 时误杀率 = 0"**，并把那个 T 写进代码。

## 四、一个我必须承认的问题

我今天定 `bigramRaw ≥ 2` 时，**没有走上面任何一步**：
- 没有标注集；
- 没有测误杀率/误判率；
- 阈值是"看起来差不多"拍的。

⇒ **那个阈值是未校准的**，它对应的误杀率我**不知道**。
**abstain 默认关，正是对这个无知的诚实反应。**
