# Generative Agents：记忆流 + 反思 + 动态检索（2026-11-02 采集）

- 来源：[arXiv:2304.03442](https://arxiv.org/abs/2304.03442)（v2，2023-08-06，cs.HC）。
- [外] 架构三件：
  1. **记忆流（memory stream）**：用自然语言存下 agent 的**完整经历记录**；
  2. **反思（reflection）**：随时间把记忆**综合成更高层的判断**；
  3. **动态检索**：按需要把记忆取回来用于规划行为。
- [外] 消融显示 observation / planning / reflection 三者对"可信行为"各自都有贡献。
- [外] 本页只读摘要：检索排序的具体公式（recency/importance/relevance 之类）在正文，**本页不引用其细节与权重**。

## 与我们对照

| Generative Agents | 我们 | 判断 |
|---|---|---|
| 完整经历记录（自然语言） | `episode`（l0/l1）+ `claims`（带 support） | ✅ 同构，且我们**逐字引用**而非模型转述 |
| 反思（综合成高层判断） | 卷（thread）+ 类级章节（`class:*`）+ 定式 | ✅ 同构，但**只用机械聚合**，不做模型反思 |
| 动态检索 | walk（顺藤摸瓜 ≤2 跳，带 why） | ✅ 同构 |
| 检索排序考虑"重要性" | 我们只用机械计数（repeat/支撑局数/时间） | 差异点：我们把"重要性"落成**可数指标**，不接受模型打分 |
| 面向"可信人类行为"的仿真 | 面向编程任务"不重复踩坑" | 目标不同 |

## 可借鉴 / 不做

- **可借鉴**：把「反思」落成**定期卷首摘要**（N9 骨架卡）——仍是机械拼接（标题 + 局数 + 代表错误 + 指针），不生成新文本。
- **不做**：让模型写反思再回灌记忆（自证污染）；让模型给记忆打"重要性"分（违反"计数不是打分"）。
