# 不相关时沉默：选择性预测（abstention）与"用覆盖率换准确率"

> **范围**：只写"**什么时候该拒绝回答**"这一面 —— 选择性预测 / 弃权（abstention / reject option）的理论与机械判据。
> 不重复 `50-判据总表`（怎么定指标）、`56-考卷污染`（尺子错了怎么办）、`44-验收方法论`（怎么证一个改动有效）。
> 访问日期：**2026-11-07**。

## 为什么写这篇

本仓的设计原则是 **"不相关时沉默"**，但实测发现：**系统几乎从不沉默**（考卷里每题都给了卡）。

我一度想用一个"沉默率"指标去抓这个问题，**结果那个指标退化了**（每题都有卡，恒为 0）。
那说明我**没有"拒绝回答"的正式理论**，只有一个模糊的愿望。

这篇把 **selective classification / reject option** 的一手文献搬过来，给出**可机械判定**的口径。

## 一、一手文献

### [外 1] 选择性分类 = 用覆盖率换准确率
Geifman & El-Yaniv《Selective Classification for Deep Neural Networks》（2017）：
> "Selective classification techniques (also known as reject option)… can potentially significantly improve
> DNNs prediction performance by **trading-off coverage**."
> "Our method allows a user to set a **desired risk level**. At test time, the classifier **rejects instances as needed,
> to grant the desired risk** (with high probability)."
>
> — https://arxiv.org/abs/1705.08500 （访问 2026-11-07）

**两个核心量**：
- **coverage（覆盖率）**：给出答案的样本比例；
- **risk（风险）**：给出的答案里**错误**的比例。

**关键**：**这两个量可以互相交换** —— 拒绝掉没把握的那部分，覆盖率下降、但风险下降得更快。

### [外 2] 风险可以被**设定**（而不是事后统计）
同文：
> "an unprecedented **2% error in top-5 ImageNet classification can be guaranteed with probability 99.9%,
> and almost 60% test coverage**"

⇒ **先定风险上限（2%），再让覆盖率自然落到 60%**。
**不是"尽可能多答"，而是"在风险 ≤2% 的前提下尽量多答"。**

## 二、对照本仓：我们一直把覆盖率当成 100%

| 概念 | 本仓对应 |
|---|---|
| **coverage** | 给了卡的比例（**接近 100%**） |
| **risk** | 给了卡但**内容与信号不相关**的比例（= 噪声注入率） |
| **reject / abstain** | **不相关时沉默**（本该有、但几乎没有） |

**我们的现状**：coverage ≈ 100%，risk 不为 0 ⇒ **用"全覆盖"换来了"注入噪声"**。

**文献的答案**：**把 risk 设为硬上限，coverage 让它降。**

## 三、机械判据（可执行）

### 判据 1：先定"风险上限"，不要先看覆盖率
```
risk = 给了卡但内容不相关的次数 / 给卡总次数
目标：risk ≤ R（R 先定，例如 5%）
coverage = 在 risk ≤ R 的前提下能达到的最大值
```
**不要把"coverage 100%"当目标** —— 那只是把 risk 抬上去了。

### 判据 2：**"拒绝"必须是一个显式的、可计数的动作**
现在卡样本里**没有"拒绝"这个类别**（只有 inject / skip）。
**拒绝 ≠ skip**：
- `skip: no-signal` = 没有输入（不是拒绝）；
- `skip: no-hit` = 没找到（**这才是拒绝**）；
- **建议新增 `action: 'abstain'`**：**找到了但判定"不相关" ⇒ 显式拒绝**，并带原因。

**没有 `abstain` 这个类别，就无法统计"我们该沉默的时候沉默了几次"。**

### 判据 3：沉默率要**在"有货可召"的题上**算
我一度犯的错：把"卡为空"当沉默率，**该指标在考卷上退化**（每题都有卡）。
正确口径：
```
沉默率 = 在"无货可召"（库里没有与信号相关的 claim）的题上，**没有给卡**的比例
```
**只有在"无货"的题上，"沉默"才有意义。**

### 判据 4：**拒绝必须比接受更"便宜"**
如果拒绝一个样本的成本 ≈ 接受它的成本，那拒绝就没有意义。
本仓里：**给出不相关的记忆会误导后续推理**（成本很高）⇒ **拒绝是划算的**。

## 四、一个可以直接落地的改动方向（**未实施，需裁定**）

在 `decidePreStep` 的 `no-hit` 分支之后，再加一条**显式拒绝**：
```
若卡上**没有任何一行**与信号内容相关（bigramRaw < 2 且 overlap = 0）：
    action = 'abstain'（**不注入**），reason = 'no-relevant-claim'
```
并把它**单列**进心跳（不与 `no-hit` 混），这样：
- **沉默率** = `abstain / (无货可召的题数)`，可机械统计；
- **噪声率** = 给了卡但 `abstain` 本该发生的比例，**应该接近 0**。

**这是把"不相关时沉默"从一句口号变成一个可验收的行为。**

## 六、一句话

**不要把"每步都给卡"当目标 —— 把"给卡的都是相关的"当目标，覆盖率让它自己降下来。**
