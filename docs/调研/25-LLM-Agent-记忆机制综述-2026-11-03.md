## 与我们对照：设计四问

| 综述里的设计维度 | 我们的答案 | 状态 |
|---|---|---|
| 记忆来源（source） | 只来自**棋谱**（会话日志 + 棋谱边），不读外部文档 | ✅ 已写进边界成文法 |
| 记忆形式（form） | 结构化：episode / claim / topic / link / thread（非自然语言大段） | ✅ |
| 记忆操作（operation） | 写：归档期机械抽取；管理：晋升/失效/裁决；读：walk + 卡 + 十道闸 | ✅ |
| 记忆评估（evaluation） | 六轴（A1–A6）+ 冻结考卷 + 安慰剂对照 | ✅ 比综述给的"主观/任务级"更硬 |

## 我们**没有**按综述建议做的两件事
1. **记忆管理里的"遗忘策略"**：综述里常见时间衰减/容量淘汰；我们用的是**有效期 + stale 遮蔽**（不删、只挡），
   理由是本仓唯一红线是"原件永不删"。
2. **多模态记忆**：不适用（纯文本工作区）。

## 可复用的三条结论
1. **设计维度必须闭合**：来源/形式/操作/评估四问缺一，记忆系统就会"能存不能用"或"能测不可信"——我们四问都有明确落点；
2. **评估要区分"记忆本身"与"下游任务"**：综述把两者分开评；我们的六轴属于前者，A2b 冻结考卷是"记忆命中"而非"任务成功"；
3. **未来方向里反复出现"记忆的可靠性与可控性"**：与我们"不命中就沉默、闸不过整卡不注入"的选择一致。

## 结论
这篇综述没有给出新机制，但提供了一个**检查清单**。用它扫一遍我们的设计：四问闭合，两处刻意偏离（遗忘策略、多模态）都有边界依据。
