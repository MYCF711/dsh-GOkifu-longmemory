# MemGPT：把 LLM 当操作系统（2026-11-02 采集）

- 来源：[arXiv:2310.08560](https://arxiv.org/abs/2310.08560)（v2，2024-02-12，cs.AI）。
- [外] 核心概念：**virtual context management**——借鉴操作系统的**分层内存**，通过数据在快/慢存储间移动，
  让 LLM 在有限上下文窗口内“看起来”拥有更大记忆。
- [外] 机制要点（摘要级）：
  1. **多级记忆**（快/慢分层）；
  2. **中断（interrupts）** 管理模型与用户之间的控制流；
  3. 两个评测域：超长文档分析、多轮会话（remember / reflect / evolve）。
- [外] 代码与数据：memgpt.ai（后演化为 Letta，见调研 07）。

## 与我们对照

| MemGPT | 我们 | 判断 |
|---|---|---|
| 快/慢分层 | 首轮一行 INDEX（快）+ 命中才展开 claims/episodes（慢） | ✅ 同构；我们更窄（只记忆，不做文档分析） |
| 中断驱动控制流 | `agent/pre-step` / `turn-stopping` 钩子 | ✅ 同构（宿主提供，不抢控制权） |
| 模型自我编辑记忆 | **禁止**（只有聚合器落账、人可纠错） | 不采用：自证污染 |
| 文档分析域 | 不做（无棋谱不入馆；文档需被会话读过） | 边界外 |

## 结论

MemGPT 的分层直觉我们已经在用（索引行 + 按需展开 + 钩子调度），差别在于**谁有权写记忆**：
它把写权交给模型，我们交给机械规则 + 人的纠错。这是产品立场，不是能力欠缺。
