# 观测证明不了因果：干预、混杂与等价类（2026-11-06 采集）

- 来源：一手文献（已读全文前 4 节，访问日期 **2026-11-06**）：
  [Stanford Encyclopedia of Philosophy · Causal Models](https://plato.stanford.edu/entries/causal-models/)（2018-08-07 首版）。
- **范围声明**：44 篇讲验收方法论、50 篇是判据总表、61 篇讲负向对照、62 篇讲停止规则；
  本篇只写**"为什么观测数据证明不了因果"**——干预的定义、混杂、马尔可夫等价类。四篇不重复页面。

## 一、观察与干预是两个不同的运算

- [外] **观察在问"已知 X=x 时 Y 如何"**："A conditional probability such as `Pr(Y = y | X = x)` gives us the
  probability that Y will take the value y, **given that X has been *observed* to take the value x**."
  而干预问的是"**把** X 设成 x **会**让 Y 怎样"：`Pr(Y = y | do(X = x))`。
- [外] **两者的机制不同**："When we merely **observe** the value that a variable takes, we are learning about the
  value of the variable **when it is caused in the normal way**… Information about the value of the variable will
  also provide us with information about **its causes**, and about other effects of those causes."
  而"when we **intervene**, we **override the normal causal structure**, forcing a variable to take a value it might
  not have taken if the system were left alone."
- [外] **干预在图上的形式化**："we represent the effect of this intervention by **eliminating the arrows directed
  into the variable intervened upon**"（"breaking those arrows"）；在结构方程里是"**replacing the equation for X**
  with a new one specifying that X = x"，"while **leaving the other equations unchanged**"。
- [外] **随机对照试验为什么算干预**："**Randomized controlled trials aim to intervene in this sense**"——
  例：用**抛硬币**决定谁来吃药，"Factors such as education and health insurance that normally influence whether
  someone takes the drug **no longer play this role** for subjects in the trial population."

## 二、观测数据为什么不够：混杂与等价类

- [外] **混杂（潜在共同原因）会让条件独立失效**："if we try to apply MCScreening_off, it tells us that _Y_ should
  screen _X_ off from _Z_. However, we would expect _X_ and _Z_ to be **correlated, even when we condition on _Y_**,
  due to the **latent common cause**."
  ⇒ **"控制了某个变量"不等于"排除了混淆"**——只要还有未观测的共同原因，条件化反而可能制造相关。
- [外] **没有时间序时，方向不可识别**："If we don't have information about **time ordering**, or other substantive
  assumptions restricting the possible causal structures… it will not always be possible to identify the causal
  structure from probability alone. In general… it is only possible to identify a **Markov equivalence class**."
  例：三个变量的分布可以同时被 `X→Y→Z`、`X←Y←Z`、`X←Y→Z` 解释 ⇒ **观测无法选方向**。
- [外] **有时间序才能唯一识别**：Pearl 定理——若"variables in V are **time-indexed**, such that only **earlier**
  variables can cause later ones"且无潜变量、满足 Markov/Minimality ⇒ "it will be possible to **uniquely identify** G
  on the basis of P."
- [外] **后门准则：什么时候观察能冒充干预**："if we can find an appropriate conditioning set Z… the probability
  resulting from an **intervention** on X will be the **same as** the conditional probability corresponding to an
  **observation** of X"（`Pr(Y | do(X), Z) = Pr(Y | X, Z)`）。
  ⇒ **不是"永远不能从观测推因果"，而是"必须找到满足后门条件的 Z 并把它观测全"**——缺一个混杂就作废。

## 三、"选择偏差"为什么是致命的（我们的形状）

本仓的 claim **只从"被抽取过的失败"里来** ⇒ 任何一个"**有没有 claim**"的分组都**不是随机分配的**：

- 分组变量（有 claim / 无 claim）本身是**结果的下游**（失败 → 被抽取 → 有 claim）；
- 于是"有 claim 的题通过率高"可能只说明"**它们本来就是更容易被抽到的题**"；
- 按第一节的语言：我们在算 `Pr(通过 | 有 claim)`，而想要的却是 `Pr(通过 | do(注入记忆))`；
  两者的差别就是**混杂**——只是这次混杂藏在**数据生成过程**里（谁能被抽到）。

**机械判据**：看分组变量是否**由处理之后的信息决定**。若是（"有 claim"必须有失败、有失败才有 claim），
该分组**永远不能**用来估计因果。

**K1+K2 是分界线**：**同一任务、只切开关、跑两次**——这就是"干预 + 配对"，此时 `Pr(通过 | do(记忆))` 可用；
其他任何设计都只是 `Pr(通过 | 有记忆)`。

## 结论

判据三句话：**观察 ≠ 干预**（一个在正常结构里看，一个在打破箭头后算）；
**没有时间序/额外假设，观测只能给出等价类，给不出方向**；**混杂未清，条件化甚至会更糟**。
最后一句：**"记忆有用吗"这个问题只能由 `do(注入)` 回答**——
凡分组变量由结果决定的设计，测的都是"谁更容易被抽到"，而不是"记忆有没有用"。
