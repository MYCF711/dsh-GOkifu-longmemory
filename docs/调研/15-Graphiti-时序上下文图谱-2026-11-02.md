# Graphiti（Zep）：时序上下文图谱的工程实现（2026-11-02 采集）

- 来源：[github.com/getzep/graphiti](https://github.com/getzep/graphiti)（README，2026-11-02）；
  论文 [arXiv:2501.13956](https://arxiv.org/abs/2501.13956)（见调研 04）。
- [外] 上下文图谱（context graph）四件套：
  - **Entities（节点）**：人/产品/策略/概念，摘要随时间演化；
  - **Facts / Relationships（边）**：三元组，带**有效期窗口**；
  - **Episodes（溯源）**：原始摄入数据 = ground truth，**每条派生事实都能回溯到 episode**；
  - **Custom Types（本体）**：用 Pydantic 定义实体/边类型（planned ontology），也可从数据里长出来（learned ontology）。
- [外] 关键工程点：
  1. 事实有**有效期**；信息变化时**旧事实被 invalidate 而不是删除**，可查"现在为真"或"某时点为真"；
  2. **增量构图**：新数据即时并入，不需全图重算；
  3. **混合检索**：语义 embedding + **BM25 关键词** + 图遍历，低延迟；
  4. 支持自定义图后端（Neo4j / FalkorDB / Neptune），MCP/REST 参考服务（README 明示参考服务无鉴权、无防注入，不得暴露到不可信网络）。

## 可借鉴
- **「某时点为真」的查询**：我们已有字段，但**还没查询面**——`cli audit` 只数「有效期已止」；
  可加 `cli facts --at <date>`（只读，机械），让"这条结论当时有效、现在失效"可查。
- **参考服务的安全声明**：README 明写无鉴权/无防注入、不得暴露——我们没有对外服务，无需处理，但值得记下这个坑。
