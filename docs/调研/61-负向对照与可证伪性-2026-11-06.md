## 一、置换检验：先有"什么都没有"的分布

- [外] **零假设是"没有差别"**："For independent sample statistics, the **null hypothesis** is that the data are
  **randomly sampled from the same distribution**."；配对样本则有两个零假设——"the data are **paired at random**"
  或 "the data are **assigned to samples at random**"。
- [外] **p 值 = 观测值在零分布里的位置**：`'greater'` 是"the percentage of the **null distribution** that is
  **greater than or equal to** the observed value"；`'less'` 反之；`'two-sided'` 是"**twice the smaller**"。
- [外] **零分布本身是产出，不只是 p 值**：返回值里有 `null_distribution`（"The values of the test statistic
  generated under the **null hypothesis**"），且原文明确要求——"the user is **advised to inspect the null
  distribution** to assess whether this method of comparison is appropriate"。
- [外] **p 值永远不为 0**：随机置换的 p 值采用"保守（高估）近似"，"the values in the **numerator and denominator
  are both increased by one**"；引文标题直接就是 "**Permutation P-values Should Never Be Zero**"（Phipson & Smyth）。
  ⇒ 跑 9999 次置换也只能说"p < 1e-4"，**不能说 0**。
- [外] **精确 vs 随机**：`n_resamples` 大于等于"不同排列数"时做**精确检验**（exact null distribution），
  否则是随机置换——"exact tests are feasible only for **very small data sets**"。
- [外] **有限精度会骗人**：原文警告"due to the use of **finite precision arithmetic**, some statistic functions
  return **numerically distinct values** when the theoretical values would be exactly equal"，可能让 p 值**大幅出错**。

## 二、负向对照怎么构造

**定义**：在**"应当完全无关"的对象上跑同一条管线**。若它也在那里"命中"，那所谓的提升就是**造出来的**。

| 构造 | 做法 | 期望 |
|---|---|---|
| **N1 跨域随机配对** | 拿 A 路的上下文去检索**完全无关**的 B 路题（"A 路完全无重合"） | 命中率 ≈ 零分布；**任何上升都是假** |
| **N2 标签置换** | 把"正确答案"的标签随机打乱再跑（等价于 permutation） | 分数回落到 chance |
| **N3 时间平移** | 把答案移到**未来**（决策时刻还看不到） | 分数不应提升（58 篇的截断自证） |

**判据（三条同时成立才算改进）**：
1. **负向对照的误判率不升**（点估计 + 区间）；
2. **正向提升超过零分布的相应分位**（不是"比基线高"，而是"比**什么都没有**的分布高"）；
3. **逐题配对**的差值方向为正（58 篇的 A3/C−B）。

## 三、什么样的"改进"会被当场抓住

| 形态 | 表现 | 负向对照怎么抓 |
|---|---|---|
| **造命中**（硬实体凑数） | 正向涨、**负向也涨** | N1 误判率上升 ⇒ 全否（T279：`negativeControl 2/2 = 100%` ⇒ 新增命中**全是造命中**） |
| **假入口**（bigram 建边） | 边数暴涨 | 在"不该入口"的样本上**假入口 56.1%** ⇒ 只能当判据、不能当边（T285） |
| **泛词伪命中** | 命中数好看 | IDF 过滤后**全数人工确认为伪命中**（T286：3/3）⇒ 过滤没误杀 |
| **净收益为负** | 正向 +N、负向 −M，N < M | 算净差（T267：**净 −3** ⇒ 否） |

## 四、"任何让指标变好的改动，必须先过这一步"（检查模板）

```
Step 0  冻结基线：改动前跑全量指标 + 负向对照，落盘（含随机种子与语料版本）
Step 1  负向对照（门）：在同一改动下跑 N1/N2/N3
        —— 误判率上升 ⇒ 直接拒绝，不看正向数字
Step 2  净收益：Δ = 正向提升 − 负向退化；Δ ≤ 0 ⇒ 拒绝
Step 3  显著性：置换/配对检验，报 p 与零分布分位（p 不为 0，报上界）
Step 4  逐题配对：同一批题 before/after 配对，报 onlyA/onlyB（58 篇的 C−B）
Step 5  人工抽查：随机 10 条"新增命中"逐条确认（伪命中率必须为 0 才采信）
Step 6  留痕：把上述六个读数写进 evidence，供下次复算
```

**一句话**：**不问"它让多少题变好了"，先问"它在不该命中的地方命中了多少"**——
后者是**门**，前者只是**收益**；门不过，收益再大也是造出来的。

## 五、对照本仓（棋院，写作时点实测）

今天负向对照至少救了四次，四次都不是"证明改进了"，而是**证明改进是假的**：

1. **T248 `negativeControl`**：用"A 路完全无重合"的样本测 B 路，**误判率不许升**——挡住"加硬实体凑数"。
2. **T279**：`negativeControl 2/2 = 100%` ⇒ **新增命中全是造命中**，T267 被否（**净 −3**）。
3. **T285**：bigram 用于建边时**假入口 56.1%** ⇒ **只能当判据不能当边**。
4. **T286**：3 条被 IDF 过滤掉的样本**全数人工确认是伪命中** ⇒ 过滤没误杀真命中。

**共同形状**：这四次的判据都不是"提升了多少"，而是"**在不该命中的地方命中率是多少**"。
而 `permutation_test` 的零分布给这件事一个形式化出口：**"什么都没有"也有一个分布**——
改进必须**跑出这个分布之外**，而不是**跑出基线之外**。

## 结论

判据三句话：**先有零分布，再谈提升**（`null_distribution` 是主产出）；
**负向对照是门，正向收益是分**（门不过，分作废）；
**p 值永不为 0**（+1 修正），所以"显著"只能报**上界**。
最后一句：**"改进了多少"永远可以被凑出来，"在不该命中的地方没命中"才凑不出来**——
这就是负向对照的全部价值。
