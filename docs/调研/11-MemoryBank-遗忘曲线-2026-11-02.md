# MemoryBank：艾宾浩斯遗忘曲线驱动的记忆更新（2026-11-02 采集）

- 来源：[arXiv:2305.10250](https://arxiv.org/abs/2305.10250)（v3，2023-05-21，cs.CL）。
- [外] 机制：
  1. LLM 的长期记忆：召回相关记忆、持续更新、综合过去交互理解用户画像；
  2. **记忆更新机制借鉴艾宾浩斯遗忘曲线**：按「经过的时间」与「记忆相对重要性」来遗忘或强化；
  3. 可接闭源（ChatGPT）与开源（ChatGLM）模型；
  4. 应用示例 SiliconFriend（长期陪伴），带心理对话微调。

## 与我们对照

| MemoryBank | 我们 | 判断 |
|---|---|---|
| 时间衰减（遗忘曲线） | **不衰减**：`occurredAt` 只用于排序与「新旧不可混」，条目永不因时间被删 | 有意不同：我们要「不重复踩坑」，忘记就违背第一验收面 |
| 重要性加权 | `repeat`（跨局重复次数）+ 支撑局数；纯机械计数 | ✅ 同构且无模型评分 |
| 强化（reinforce） | 同类错误再次发生时，claim 的 support 与 repeat 增长 | ✅ 已有 |
| 用户画像综合 | 不做（面向模型，不做人设） | 边界外 |
| 遗忘 = 删除 | 我们只**遮蔽可见性**（invalidated / validityOk=false），原件保留 | 更保守 |

## 可落地候选

- **N12 衰减只作用于「排序」不作用于「存留」**：卡片排序加一个弱时间项（越久远越靠后），
  但**绝不删除**、也不降低 support 计数；可用现有 `occurredAt` 实现，零新字段。
  - 风险：会压低老坑的优先级；与「不重复踩坑」冲突，**默认关闭**，需 A2/holdout 对照才允许开。

## 结论

MemoryBank 的“遗忘”与我们“不忘记”是产品分歧点，不是能力差距；可借鉴的只有「弱时间项排序」，
而且必须用 holdout 证明不伤 A2 才能上。
