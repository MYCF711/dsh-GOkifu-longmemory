# 单层记忆越存越差：三层经验图、压力遗忘与「对比边」防负迁移（2026-11-08 采集）

- 来源：[arXiv:2610.19386](https://arxiv.org/abs/2610.19386)（**STRATA: Self-Maintaining Structured Experience Graphs for Self-Evolving Language Agents**；
  作者 **Guanhua Zhu / Hanwen Li / Zhi Wei / Mengnan Du / Chenxi Yuan**；v1 **2026-10-14**；
  正文 [HTML](https://arxiv.org/html/2610.19386) 已读 Method 全节、Results and Analysis（主结果/单层失败/增益来源/消融/负迁移案例/效率）、附录 A–I 部分，访问日期 **2026-11-08**）。
- **范围声明**：`docs/调研/00` 的 01–94 已覆盖 MemUse 的使用点评测（#92）、Zep Agent Skills 的过程编译（#93）、经验复用与负迁移的受控实证（#94）。
  本篇是一个**完整系统**（不是受控小实验）：它把「经验」拆成**三层图 + 类型化边**，并给出**自维护**（反射/压缩/遗忘/对比边）的整套机制；
  与 #94 互补：#94 回答「抽象为什么更抗负迁移」，本篇回答「**怎么把抽象、去重、遗忘、对比做成可运行的图**」。
- **一句话结论**：[外] 单层、只靠 embedding 相似度的经验池会**越存越差**（A-Mem 在 168 题时第一、812 题时第七；每任务注入 41.9 行 vs STRATA 23.3 行——**注入更多 ≠ 注入更好**）；STRATA 用**三层（atomic/workflow/meta）+ 类型化边**、按 **operation/target 标签**加权的多锥相似度、**带桥保护的压力遗忘**（只删非割点）、**社区检测诱导 meta 框架**、以及**对比边**（把「同对象、相反操作」的经验显式连起来、渲染成"别混淆"）来同时拿泛化与防负迁移；组件消融里，**标签项（−13.1）与对比边（−6.5）贡献最大**。

## 一、它问的问题

- [外] **单层池的三个病**：轨迹、提炼出的 workflow、推理条目**全落在一个无类型池**里，只用 embedding 相似度检索；**从不遗忘、从不去重**；因此容易**负迁移**——「表面相似但方向相反」的经验被召回、具体步骤被**逐字照抄**，主动害人（原文例子：「加热锡直到熔化」vs「冷却锡直到凝固」）。
- [外] 单层记忆的失败有一个可预测的**签名**：**池子小时有竞争力，池子变大后变差**——作者用 A-Mem 验证：AppWorld 从 Test-Normal（168 题）到 Test-Challenge（417 题）优势翻转；WebArena（812 题）上 A-Mem 在 Flash 上排第 7/8，低于 Flat-Memory、Hermes、MemGen，只高于无记忆。
- [外] 作者把「结构 vs 抽象」的取舍讲得很直白：**具体的程序性记忆（AWM/Hermes）迁移强、但危险**（可逐字执行）；**抽象推理条目（ReasoningBank）安全、但弱**；对比边想让前者保留迁移强度、又不留灾难性失败。

## 二、方法：三层图 + 五种自维护

### 2.1 三层节点与四类边

- [外] 节点带类型 `τ(n) ∈ {atomic, workflow, meta}`：**atomic** = 最小可复用单元（一个工具/API、参数化代码片段、专门子角色）；**workflow** = 整个任务的一般化过程；**meta** = 从一族相似 workflow 抽象出的范式。
- [外] 边是**类型化**的：`call`（workflow→atomic，有序）+ 三种演化关系（sources→target）：`generalizes`、`merged_from`、`contrasts`。
- [外] 维护用一张**派生图** `W = (workflow 节点, 相似边)`：对 workflow 的 union-kNN 图，每轮重算、**从不存储**；社区检测与割点保护跑在 `W` 上，其余跑在 `G` 上。
- [外] 每个节点有**多个文本视图**（content「做什么」/ index「何时用、目标」）+ **结构化标签** `T(n) ⊆ {app:*, op:*, obj:*}`（应用/操作/目标对象，是节点属性不是节点）；查询也解析进同一标签空间。

### 2.2 多锥相似度（本仓最该抄的一条）

- [外] 单一 content embedding 会把**同材料、不同操作**的经验混为一谈。STRATA 用四项加权：`s = 0.40·cos(content) + 0.25·cos(index) + 0.30·Jaccard(tags) + 0.05·词面重叠`。
- [外] **标签项是加性权重、不是乘性门**；权重 0.30 使它成为**最大的非内容项**，也是**唯一**能把「同对象、相反操作」的内容近重复分开的项（消融里去掉它平均掉 **13.1** 分，最大的一项）。
- [外] **检索返回子图**而不是孤立条目：按 `s + 0.15·层偏置` 排序（meta 偏置最高），**只有原始分 ≥ 0.35 的种子**才准入；**一个都不过就整卡不注入**——原文：「running without memory beats being misled」（不注入胜过被误导）。围绕 top-k 种子拉入其 meta 父节点（父节点自己也必须过 0.35，防「万能 hub」泄漏）、其调用的 atomic、以及**对比邻居**；渲染顺序 **meta → workflow → atomic**（先读原则、后可执行）。

### 2.3 类型化反射 + 自适应阈值

- [外] 每局后一个 master router 看任务/结果/轨迹，分派给 skill/code/role/workflow 四类子反射器；**atomic 只从解出来的局结晶**；workflow 子反射器是阈值驱动。
- [外] 阈值必须自适应：等价任务对在一个应用里相似度 ≈0.4–0.5、在另一个里 ≈0.8，单一全局阈值要么**过度合并**、要么**过度碎片化**。做法是按**主导标签分组**，把每组的分位数向全局先验收缩（经验贝叶斯，`κ=30`）：`τ = λ·Q_p(S_g) + (1−λ)·G`，`λ = n_g/(n_g+κ)`；样本多的组信自己、稀疏组回退先验。
- [外] 三种决策：`s > τ_high` ⇒ **noop**（近重复）；`τ_low ≤ s ≤ τ_high` ⇒ **add_bullet**（只把差异记成一条 bullet）；否则 **create**。当前分数在决策**之后**才记入组，**决策不污染自己**。
- [外] **失败局永不结晶「do this」过程**；最多给最近的 workflow 挂一条 **pitfall bullet**，渲染成「要避免的东西」。

### 2.4 压力遗忘 + 桥保护（「哪些该退役」的直接答案）

- [外] **只在 workflow 层遗忘**。每条 workflow 有一个质量分：`Q = 0.35·z(rank(activation)) − 0.65·z(rank(age))`——activation 是它在存活邻居里的**相似度加权度数**（中枢保留），age 是**竞争性年龄**；用排名而不是原值，让两个不可比的信号可比。
- [外] **年龄在线更新**：每次检索所有候选 `α=0.02` 变老；**被检索到但没被选中的**按 `β·w_i·(1−margin)` 罚（「差一点输掉」的竞争者老得最快）；**选中的**按 `γ=0.5` 回春。
- [外] 存活 workflow 超过上限时，删最低 Q 的节点到 `cap·(1−0.15)`（**滞回**防抖）；孤儿 atomic 与失去支撑的 meta 级联删除。
- [外] **桥保护（关键 bug 修法）**：若最低 Q 节点是 `W` 的**割点**，删了会把一个社区劈开、下一轮社区检测把一族任务裂成两个 meta。所以删的是**最低 Q 的非割点**（每轮 Tarjan 求割点，`O(|V|+|E|)`），只有候选全是割点才退化为无约束最小值——**收集永远有进展**。

### 2.5 社区检测诱导 meta + 对比边

- [外] meta 由**社区结构**触发（不是数孩子）：workflow 对在 `s_nn` 超过「按组自适应阈值（κ_E=6，组内默认 0.40）或跨组固定 0.55」时连边，每节点保 6 条最强边；Louvain（resolution 1.5）出社区；只有**大**（`|C| ≥ N_min`）、**紧**（conductance `< 0.6`）、**新**（到最近 meta 的距离 `≥ 0.6`）的社区才升为 meta，否则吸收进匹配的 meta。作者记录：早期固定阈值下 153 个候选对只有 3 个过线、一个 meta 都没形成。
- [外] **对比边**：内容维度会把「同对象、相反方向」评为高度相似；标签项能压低但**不能总防住召回**，而召回的具体过程可能被逐字执行。对比边是**双向演化边**：`contrast(a,b) ⇔ op(a) 与 op(b) 相反`（按固定反义操作词表：`{heat, cool}`、`{create, delete}`），**不要求 obj 相同**（负迁移常跨对象，如铅熔化过程误导锡凝固任务）；检索到种子时把对比邻居拉进子图，渲染成醒目的 **"do not confuse"** 警告，而不是一条普通过程。与「写时收紧单条过程的前置条件」不同，它是**读时**的、关联两条对立经验。

## 三、结果（数字都来自正文/表）

- [外] **主结果**（三个种子）：Pro 骨干 7 列里 6 列最好、Flash 7 列里 5 列最好，其余第二；四基准平均最强。AppWorld Test-Challenge SGC **46.5±2.3 vs A-Mem 42.2±2.6**；WebArena **45.6±1.6 vs MemEvolve 41.0±2.2**；ALFWorld **98.6±0.9 vs MemGen 96.3±1.9**；在 AppWorld Test-Normal 与 ScienceWorld 上**不能**与最强基线统计分开（作者自己说明 ScienceWorld 23 题、标准差 3.6–15.0）。
- [外] **负迁移在聚合上可见**：Hermes 在 AppWorld Test-Normal 只有 **30.4/35.8**（TGC/SGC），远低于无记忆 **62.8/66.9**；ScienceWorld **48.3/55.8 vs 75.7/80.6**。「记忆让 agent 比没有记忆还差」= 召回到的经验被错误执行的直接证据。
- [外] **单层记忆的退化签名**：A-Mem 从 Test-Normal 到 Test-Challenge 优势翻转（Flash `+0.4/+3.4 → −4.3/−6.3`；Pro `−1.2/+1.8 → −2.2/−4.3`）；WebArena 812 题上 A-Mem Flash **28.4**（第 7/8），低于 Flat 30.7、Hermes 31.6、MemGen 29.5；Pro 38.7（第 4，落后 MemEvolve 41.0、ReasoningBank 40.3）。**注入行数**：A-Mem 41.9、Flat 35.6、STRATA 23.3——**注入更多不等于注入更好**。作者同时把 confound 说清：Test-Challenge 不只是更大，也更深、应用构成不同（amazon 212 题在 Normal 里没有），所以这是**两条一致观察**，不是受控的规模实验。
- [外] **增益集中在长尾类别**：AppWorld Test-Normal 的 phone（22 题）54.5→59.1；Test-Challenge 里三个最大增益都落在 <10 题的小类，而两个最大类只涨 +3.8（amazon，212 题）/+3.2（gmail，126 题）；WebArena 集中在 shopping_admin（31.5→41.8）与 gitlab（33.8→43.8）两个最「组合式」的站点；WebArena 812 题被压成 **112 条 workflow、16 个 meta**。
- [外] **组件消融**（Pro，平均）：Full **72.9** > w/o tag **59.8**（−13.1）> w/o contrast **66.4**（−6.5）> w/o adaptive threshold **67.0**（−5.9）> w/o meta **68.2**（−4.7）> w/o pressure GC **70.7**（−2.2）。**对比边的代价是集中的**：ALFWorld −9.1、ScienceWorld −18.0，而 WebArena 只 −1.8——「只在前提成立处出现」正是机制证据，不是通用正则。
- [外] **负迁移案例**：ScienceWorld `find-living` 族，Hermes 在 Flash **−100**、Pro **−80**（无记忆能解）；记忆召回一条「表面相似但方向相反」的具体过程，被照抄进负分状态。附录 F 隔离修复：对比边把 ScienceWorld 从 **78.7→89.8（手工边）→96.7（规则词表）**，ALFWorld **89.5→98.6**；检索在 3/3 个陷阱任务上都注入了「相反警告 + 正确方向经验」，但最终成功还取决于骨干是否听。

## 七、能借的三点（都能做成机械规则）

1. **op/obj 标签 + 对比边**：claim 增加机械标签 `op`（从命令动词/错误特征抽）与 `obj`（文件/工具/对象）；`op` 相反、`obj` 相同 ⇒ 建 `contrast` 双向边，渲染时并排 + 警告。这是把「同词面反方向」的负迁移从**排序问题**变成**结构问题**。
2. **退役用「非割点」**：在 claim 的相似图上算割点（Tarjan，O(V+E)），退役候选必须不是割点；质量分 = 激活（相似度加权度数）vs 竞争年龄（检索到但未选中者老得更快）。避免退役把一类坑的**唯一桥**删掉。
3. **meta 层用「社区 + 三道门」**：不要按计数硬升；要求社区**大、紧、新**（`|C|≥N_min`、conductance<0.6、到最近 meta 距离≥0.6），否则吸收进已有 meta。增益会集中在**长尾类别**——这正好是 T39/T40 想测的「同类不同坑」泛化。

## 八、明确不借的三点（附理由）

1. **不借 embedding 相似度主干**：本仓不做向量检索（边界成文法）；`content/index` 两项换成我们的词面 + 坑类/工具族键，`tag` 项照借（它本来就是符号 Jaccard）。
2. **不借 LLM 反射者/路由器**：违反「禁止模型评分参与晋升/排序/存留」；我们只借它的**决策三分**（noop/add_bullet/create）与**阈值自适应**的统计形状，实现成机械规则。
3. **不借「自动删节点」**：本仓原件永不删、只遮蔽可见性；论文的「删最低 Q」在我们这里应变成**降级/退役标记**（T3 指针档 / T8 冷却），保留原件。

## 九、对本项目的可执行建议（对应三个痛点）

1. **洞见层泛化（T39/T40）**：把洞见层做成**meta 层**（多条同类 pit 陈述 → 一条 meta），用「大/紧/新」三道门控制晋升；评测时按**坑类频次分层**报告（论文的增益集中在 <10 题的小类），不要只看总平均——否则长尾泛化会被大类淹没。
2. **记忆过拟合**：加两个机械指标：①**池子规模分层命中率**（按 claim 池大小分桶看命中率是否随池子变大而下降，对标 A-Mem 的 168→812 退化）；②**注入行数**（对标 41.9 vs 23.3：「注入更多 ≠ 注入更好」）。退役/聚合先按「非割点 + 质量分」跑离线试算，不改可见性。
3. **恢复事实跨任务迁移**：给恢复事实的 `op/obj` 建 `contrast` 边（同对象反操作 → 并排警告），并在跨坑类评测里单独统计「对比边命中」与「负迁移」；T35 的 file-exists 失效与对比边是**两件事**：前者是「条件不成立」，后者是「方向相反但都成立」。
