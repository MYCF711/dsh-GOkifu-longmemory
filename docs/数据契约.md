# 数据契约（M1 冻结 · v0.1）

> 实现前冻结。字段一旦冻结，新增字段可以，改语义不行（改语义 = 新版本 + 迁移）。
> 与 AGENTS §4 一致；本文件是逐字段的可测试定义。

## 1 · 会话日志（输入，只读）

### 1.1 帧

- 文件 = 多帧 zstd 拼接。首帧 = header；后续帧 = 事件批次。
- 解码契约：`readFrames(buf) -> {frames: Buffer[], truncated: boolean}`。
- 坏尾：返回已解前缀 + `truncated:true`，**不抛**。

### 1.2 header（首帧 JSON）

```js
{ type:"session", version:4, id:"session-…", createdAt:<epoch ms>,
  cwd:"<工作区路径>", isSeeded:false, delegationDepth:0, agentPreset:"standard" }
```
- `version !== 4` → 抛 `logread: unsupported version`。
- `cwd` 是**工作区**；棋谱里的 `cwd` 不是（实测为 profiles\desktop）。

### 1.3 event（每帧内的 JSONL 行）

```js
{ type:"<event type>", seq:<非负整数>, time:<epoch ms>, data:{…}, ignorable?:true }
```
- `seq` 全局单调；`time` 必须存在（DSH 校验 `typeof time !== 'number'` 即拒绝）。
- 解析契约：`parseEvents(frames) -> {header, events, truncated}`；跳过空行；坏行 → `{badLines:n}` 不抛。

## 2 · episode（棋谱）

```js
{ id:"ep-<sid8>", sessionId, scopeKey:"w:<规范化cwd>",
  startedAt, endedAt,            // header.createdAt 与最后事件 time（或末事件缺失时=startedAt）
  firstEventAt, lastEventAt,     // 事件 time 的 min/max（无事件则 = startedAt）
  timeSource:"event"|"inferred", // 缺 time 时 inferred
  recordedAt,                    // 入馆时间（M1 只读，不入馆 → 可为 null）
  agentPreset, delegationDepth,
  closure:{ logPath, graphPath, seqFrom, seqTo, nodeIds:[], edgeIds:[] },
  l0:"", l1:"",                  // M2 填
  signals:{ failures:0, successes:0, unsettled:0, constraints:0, tools:[] },
  threadIds:[], state:"archived" }
```
- `sid8` = sessionId 去掉 `session-` 前缀后的前 8 位；`scopeKey` 用小写盘符 + 正斜杠规范化。
- 纯函数 `buildEpisode({header, events, graphPath, logPath, now})`；不读盘（读盘在 R01/R02）。

## 3 · graph（输入，只读）

- `graph.json`：`{version, nodes:{}, edges:{}, nextNode, nextEdge, foldCount, …}`。
- `graph.json.delta.jsonl`：每行一个 delta 帧；按行回放；坏尾 → 前缀 + `truncated:true`。
- `loadGraphAt({basePath, deltaPath}) -> {graph, frames, truncated}`；幂等（同输入两次同结果）。

## 4 · topic / mention / link

```js
topic   = { id:"t:<kind>:<hash8>", kind, key, df, firstSeenAt, lastSeenAt }
mention = { from:{episode,nodeId?,edgeId?}, topic, seq, quote, weight, occurredAt }
link    = { a:{episode,nodeId?}, b:{episode,nodeId?}, kind, topics:[], why:"", weight, occurredAt }
```
- `kind ∈ repo|scaffold|dependency|tool|file|domain|error|term|goal`。
- `weight`：硬边=1；软边=0.5×IDF 归一（0..1）。
- `why` 必填：命中的 topic key 列表（逗号分隔），空 why 的边不建。

## 5 · index.md

- 按 scope 分节；每局一行：`- <YYYY-MM-DD> <ep-id> · <l0≤60字> · fail=<n> · topics=<top3> · links=<n>`。
- 必须含："未列出 ≠ 不存在；完整清单见 index.md 树"。

## 6 · 存储（M2 起）

- 根：`<DSH_HOME>/memory-context/`；子目录：`episodes/ topics/ links/ threads/ joseki/ adjudications/ claims/ journal/`。
- `manifest.json`：`{version, user:"owner", createdAt, updatedAt, counts, checksums, pathPolicy:"relative"}`。
- 路径一律相对 `memoryRoot`；不存绝对路径。

## 7 · walk / inject（M3 契约）

### 7.1 信号（当前会话 → 检索输入）

```js
signal = { kind:"root-message"|"activity"|"user-explicit",
           terms:[string], entities:[{kind,key}], at:<epoch ms> }
```
- `terms` 来自根 user 消息的判别性词；`entities` 来自当前活动的文件/命令/域名/错误。
- **只有命中主题索引才启动跳转**；未命中 ⇒ 零注入。

### 7.2 walk（顺藤摸瓜）

```js
walk({ signal, store, depth=2, limit=5, budgetTokens=500 })
  -> { hits:[{episode, nodeId?, link, why:[topic], weight, occurredAt}],
       path:[{from, to, why}], omitted:{count, reason}, tokens }
```
- 深度 ≤2；每跳必须有 `why`；条数 ≤limit；token ≤budget。
- 排序：失败教训（edge.result=failure）优先，其次约束/偏好，最后定式候选。
- 只读 store；不写。

### 7.3 inject（记忆卡）

```js
card = {
  indexLine: "MEMORY: <index 路径>（scope=…, N 局, 未列出≠不存在）",  // 首轮一行
  section:   "<memory-ledger>…</memory-ledger>" | null,             // 命中才展开
  claims:[{text, state, occurredAt, source:{episode,seq,edgeId?,quote}}],
  omissions:"…",
  tokens, shadow:true
}
```
- **shadow 模式**：只记录 `{card, signal, at}` 到 `evidence/shadow/`，不注入模型上下文。
- 每条 claim 带 `occurredAt` 与 provenance；渲染日期用绝对时间。
- 禁止祈使句/下一步/许可；只陈述事实。

## 8 · 版本与拒绝

- `memoryGraph.version` 当前 `1`；未知版本 `fromJSON` 抛 `unsupported version`。
- 任何 sidecar 读取先校验 manifest；缺 manifest → 拒绝并提示 `rebuild`。

## 9 · claim（2026-11-02 补齐；此前只写在 AGENTS §4.8）

```js
claim = {
  id:"c-<hash8>", kind:"fact"|"rule"|"antipattern"|"preference"|"pattern",
  text,                    // 事实陈述；类级章节以 `class:<name> · …` 开头
  scopeKey,                // `w:<工作区>` 或 `u:<用户>`
  state:"observed"|"candidate"|"semantic"|"disputed"|"invalidated"|"stale",
  support:[{episode, threadId?, nodeId?, edgeId?, seq, quote, occurredAt}],
  counter:[{episode, …, seq, quote, occurredAt}],
  occurredAt,              // 首条支撑发生时间（epoch ms）
  validFrom,               // = occurredAt（出生）
  validTo,                 // 终止时间：人纠错 / 核验失败时写入；null = 至今有效
  recordedAt,              // 入馆时间（第二时钟）
  validity:{type:"none"|"file"|"commit"|"version", value},
  validityOk,              // 归档时核验结果；false ⇒ 不注入（只遮蔽）
  preconditions:[{check, value, why}],
  counters:{support, counter, injections, lastInjectedAt},
  repeat,                  // 派生字段：读侧按 support 局数计算，不落盘（2026-11-02 审计 P2-2）
  supersedes:"c-…"|null    // 保留字段：当前无生产者，冲突链尚未启用
}
```

> **字段生产状态（2026-11-02 审计后）**：`validFrom` 已落盘（= `occurredAt`，历史条目除 26 条无 `occurredAt` 者外均已补）；
> `threadIds` 恒为 `[]`、`supersedes` 恒为 `null`（保留字段，无生产者）；`repeat` 由 `walk` 读时派生。
> **历史 claim 不做回溯改写**：0.58 之前写入的 26 条 `validFrom` 为 `null`（它们都有 `occurredAt`；只是旧代码没写该字段）。
> 归档每次会**重写派生 claim 记录**（同 id 覆盖），这属于派生数据重建，不是改写原件；未被派生集覆盖的旧记录原样保留。

**不变量**：
- 只增不改：任何冲突加 `supersedes` + 时间戳，不删条目、不改写 `text`；
- 无源不入：`support` 至少一条；`seq/quote` 必须在闸 5 可核；
- 无时不入：`occurredAt` 必须是真实事件时间；缺则整条丢弃（不是填 now）；
- `validFrom ≤ validTo`（若 `validTo` 存在）。

## 10 · adjudication（多成员裁决 / 人纠错）

```js
adjudication = { id:"ad-<n>", target:"c-…"|"j-…", level:"L2-multi-member"|"L4-human-correction",
  n, votes:[{member, verdict:"support"|"oppose"|"insufficient", evidence:[{episode,seq,quote}]}],
  agreement, dissent:[…], decision:"promote"|"hold-disputed"|"invalidate"|"correct", at }
```
- 归档时**只有** `L4-human-correction + decision=correct` 会被回填：目标 claim 加 counter、`validTo=at`、`state=disputed`；
  幂等（同一纠错重放不重复计数）；L2 与 `hold-disputed` 不动 claim。

## 11 · thread（卷 / 棋书视图）

```js
thread = { id:"th-<hash8>", title, scopeKey, kind, topics:["t:…"], kifus:["ep-…"],
  kifuCount, links, parentThreadId:null, state:"open", createdAt, updatedAt,
  headline:"<类名> · N 局 · 最近 YYYY-MM-DD · 代表：<l0≤60>" }   // 机械拼接，不调模型
```
- 卷是**视图**：多对多、删卷不删谱；`class:*` 主卷不套「df ≤ 10%N」上界（否则最该成册的类永远不成卷）。

## 12 · 巩固（consolidation，2026-11-02 显式化）

| 项 | 契约 |
|---|---|
| 输入 | 单条 claim（`kind=antipattern` 且 `errorKeyOf(text)` 命中 8 类之一） |
| 输出 | 一条类级章节 claim（`class:<name> · <代表错误>`），`support` = 各单条支撑并集 |
| 幂等 | id 由「类名 + 作用域」决定；重复归档不新增 |
| 副作用 | 无：不删、不改写既有 claim、不写会话日志 |
| 触发 | `scripts/archive.mjs` 每次归档；≥2 局支撑才补 |
| 迁移说明 | 0.34 起 `promoteClaim` 已直接产出带 `class:` 前缀的正文，因此本步对**新库基本空转**（`class-audit` 显示缺 0）；它的价值是给 0.34 之前的老库补章节 |

## 13 · 配置（插件，`src/plugin.mjs` DEFAULT_CONFIG）

```js
{ enabled:true, shadow:false, autoBuild:true, autoArchive:true, autoArchiveMinutes:30,
  storeRoot:null, shadowDir:null, budgetTokens:500, limit:5, oncePerSession:true,
  repeatHint:true, repeatHintAfter:2, repeatHintMax:1,
  crossScopeClass:false,      // Q18 未裁定前必须 false
  probeValidity:true, now:null }
```
- `crossScopeClass:true` ⇒ 仅 `class:*` 可用跨工作区证据，卡片行尾标 `[跨项目]`，A5 统计分桶（`crossMarkedLines`）。
- 任何配置解析失败 ⇒ 回落默认值并 `warn`，不抛到宿主。

## 14 · 版本与拒绝（补充）

- `claim.validTo` 与 `thread.headline` 是**新增字段**：缺失按 `null` 处理，不做迁移；
- 旧库（0.36 之前）没有 `validFrom`：查询时按 `occurredAt → support 最早时间` 回退，**不重写历史文件**。
